# Nate

Nate 是使用 Swift、AppKit 和 TextKit 2 构建的 macOS 文本与代码编辑器。它提供多窗口、多标签、快捷替换、批量文本处理，以及默认每秒推进的自动保存。持续输入时也会保存；未命名文档写入独立恢复目录，无需先选择文件位置。

## 每秒保存与内容保护

原文件和恢复存储是两条独立通道。保存固定已提交正文快照，后台写入、同步并复验文件身份与内容；保存期间的新输入继续等待下一周期。没有实际字节变化时不写原文件。自动保存不清空撤销历史，输入法候选确认前不进入正文和保存快照。

打开、恢复关联与明确保存同时检查解析后的路径和磁盘文件身份。同一文件已由其它标签或在途文件动作持有时，恢复正文继续作为独立文档保留，原路径等待再次核验。保存副本也会检查硬链接，可以另选独立目标。

恢复正文按不超过 1 MB 的不可变分块保存，局部编辑复用既有内容。每个分块独立校验，全部同步后才发布有序清单和工作区索引；恢复时直接重建正文树，支持读取既有完整快照。当前恢复预算为每文档 1 GB、每工作区 2 GB 和 1024 个文档，清单最多 8 MB；超限保留现有记录并显示失败。分块摘要缓存只保留有限元数据，不持有关闭后的正文。

活动标签与固定标签状态按同一周期持久化。只切换标签时更新工作区索引，复用已有正文清单；自动恢复保留文档修订，后续编辑、撤销和重做继续使用新的单调修订。

自动恢复另行保存窗口的位置和大小、各窗口的标签顺序、活动窗口，以及分屏方向和分隔比例。可见编辑视图各自保留完整选区、文字方向、软换行、缩放和逻辑滚动位置。已访问的后台标签也保留独立选区和顶行。共享正文在其它窗口被修改后，这些位置会沿编辑修订映射到当前正文。恢复选区与滚动前会核对正文身份和修订。显示器变化时，窗口位置会限制在当前可用区域。布局归档损坏时，Nate 保留原归档，并依据有效正文索引建立窗口。

“视图 → 标签栏布局”可选择水平、左侧垂直或多行标签，选择会独立保存。多行随窗口宽度排列，最多显示四行，其余标签纵向滚动；垂直标签使用独立的左侧区域。各布局均可拖动标题调整顺序，边缘悬停沿对应方向滚动；右键也可左移、右移或移到首尾。长标题在有限宽度内省略，悬停仍显示完整路径。

每扇窗口使用自己的标签顺序。移动非活动标签和切换布局保留当前正文、输入法候选、克隆光标及固定状态。单窗口的标签重排按实际顺序保存索引并复用正文清单。文档集合、顺序或布局改变后，旧拖动失效。未知或损坏的布局偏好保留原归档并提示，本次采用水平布局。

“文件 → 新建窗口”打开独立窗口和空白文档。“窗口 → 在新窗口克隆当前文档”让两个窗口编辑同一份正文，共用撤销历史、文件身份、只读状态和保存通道，各自保留光标、滚动位置与当前视图的显示状态。

可以将标签拖到另一扇窗口可见的标签栏，插入线显示放置位置。也可以从标签右键菜单选择“移动到另一窗口”，或从“窗口”菜单移动当前标签。目标窗口会接手该标签的光标和滚动位置。目标已经显示同一文档时，沿用它自己的视图。关闭克隆标签保留其它窗口的正文和保存任务。关闭窗口时，独有标签转入仍打开的窗口。关闭最后的窗口时进入正常退出流程，等待正文与恢复通道完成保护。

按 F8 或选择“视图 → 切换分屏焦点”可将键盘输入交给另一侧正文。现有的自定义 F8 绑定继续生效。每侧保留自己的光标和滚动位置，原输入可以安全确认时才交接焦点。“视图 → 显示工具栏”可暂时收起当前窗口的工具栏，文档列表仍可从“窗口”菜单打开。“窗口 → 当前窗口置顶”可单独将当前窗口移到普通窗口之上。

“视图 → 垂直同步滚动”和“水平同步滚动”分别控制当前双视图，默认关闭。共享正文按真实顶行和行内偏移同步，目标行被折叠时定位到最近可见标题并保留各自折叠；不同文档按完整可滚动范围的比例移动。水平同步采用相同横向位置，两个方向可分别启停。开启本身不移动视口、光标或焦点，后续滚动才同步；候选输入、编辑保护或等待排版更新时保留另一侧原位置。

同步开关仅在当前窗口运行期间保留，恢复单视图后保留选择，重新分屏继续采用；重新启动默认关闭。关闭克隆会先解除原滚动观察，旧视图和其它窗口的通知不能推动后来视图。同步不改写正文、选区、编码、历史或全局用户配置。

“视图 → 面板停靠”可以把目录、项目、函数列表或搜索结果与输出放到窗口四边，也可以打开独立浮动面板。同一边的多个工具通过标签切换，可拖动分隔线调整停靠区域。关闭浮动面板后，可从对应的显示命令重新打开。窗口恢复会一并保留面板位置、尺寸、可见性和组内活动标签。

“视图 → 文档地图”在右侧显示当前编辑视图的正文概览和可见范围。单击或拖动地图即可滚动，保留原光标和选择。地图在后台使用有界的行与字节采样，长文件会合并预览行。它可以同其它面板一起停靠、组合或浮动。分屏切换焦点后，地图跟随得到焦点的正文视图。

工具栏的“文档列表”和“窗口 → 文档列表”提供完整标签列表；窗口菜单展开时更新当前顺序。同名文件附加目录，临时文档明确标识，仍重复时使用稳定编号；标签与列表共用名称和独立的失败、固定、只读及待保存标记。长名称保留两端并限制展示长度，路径提示保留完整原路径。打开或取消列表保留候选，实际切换才通过统一入口确认原输入；集合、顺序或布局改变后，旧列表不再执行激活。

“文档列表排序依据”可选标签顺序、名称、扩展名或路径。名称、扩展名与路径采用系统自然排序，例如 `file2` 排在 `file10` 前。缺少扩展名或路径的文档排在相应列表末尾，同键文档沿标签顺序显示。排序只影响当前窗口的文档列表。

从工具栏的“文档列表”或“窗口”菜单选择“搜索已打开文档…”，输入名称或路径即可筛选当前窗口的标签。结果沿用列表排序和状态标记，同名文件显示各自路径。方向键移动选择，Enter 或双击切换，Esc 取消。搜索期间可以浏览结果，确认前始终保留当前文档。

“窗口 → 标签切换顺序”决定 Ctrl+Tab 和 Ctrl+Shift+Tab 如何遍历。默认按标签栏顺序，也可改为最近使用顺序。按住 Control 连续按 Tab 可循环浏览，Shift 反向，松开 Control 后把最终停留的标签记为最近使用。各窗口独立维护访问顺序，切换偏好随应用保存。

检测到外部变化后暂停覆盖。编码不可表示、权限不足、目标缺失或强同步失败会保留缓冲区并显示原因。恢复能力截至最近一次成功持久化的完整快照；文件写入与恢复副本的成功分别确认。硬链接目标需要另存为，以免安全替换静默改变共享语义。

原文件读取、写入和移动使用 macOS 文件协调，等待访问权可取消并设有上限。取得协调访问权后仍复验目标和磁盘基线；原始字节与 SHA-256 证据由同一次流式读取生成。底层系统调用完成后仍确认其实际结果，恢复副本的成功独立确认。

文件访问只接受主机为空或 `localhost` 的 `file` URL，网络盘使用已挂载目录中的路径。进入平台协调、读取或写入之前校验完整解码路径，拒绝 NUL、不可解码的路径及带远程主机、凭据或端口的文件 URL。字面的 `%00`、`%FF` 等合法文件名和正文中的 NUL 保持原样。恢复与保存备份目录使用相同边界，无效配置不会先被转换成另一个可写目录。

BOM 只在完整文件的编码探测入口识别并移除一次。正文、恢复分块、剪贴板片段、宏输入、配置名称、命令参数、字节转文本结果与外部命令输出中的前导 U+FEFF 保留为原文；连续标记不会被反复删除。已确定为 UTF-8 的字段必须与回编码逐字节一致，非法序列整体拒绝，不用替代字符或丢弃前导字符后继续处理。

目标目录同步所需的读取权限在替换原文件之前取得。macOS 隐私授权可能使目录访问持续等待，此时任务显示实际阶段，原文件保持原状；收回尚未使用的发布权后，迟到的目录访问也不能继续覆盖。

取消与文件发布通过单次权限确定先后。已进入发布的请求继续确认实际结果；保存点须同时匹配本次文件身份和固定字节摘要，期间发生的外部写入不会被当成本次保存成功。

“工具 → 文件写入任务”显示排队、编码、系统协调、临时写入、同步、发布和保存后确认的真实阶段，并保留最近 100 条完成记录。撤销只收回尚未使用的发布权，未返回的系统动作继续可见。关闭和目标切换最多等待 30 秒；停止等待后保留正文与任务。退出时仍有未返回的文件发布或进程启动，会取消退出，避免把未决外部动作当成已经停止。

关闭、退出和进入监视分别持有编辑暂停状态，只有全部相关流程解除后才恢复输入。退出开始时立即推进独立恢复，等待原文件期间继续保护最后提交的正文；取消退出只解除退出暂停，仍在确认关闭或监视的文档保持保护。已经开始的标签关闭及目标关联需要先确认，再决定最终退出工作区。

原文件与读取通道各以两个线程处理阻塞 I/O，超过 30 秒仍未返回时提供有限替补，各最多增加 8 个线程；达到未返回预算后暂停新动作并拒绝尚未开始的请求。每个通道最多排队 128 项，拒绝会释放未执行快照。恢复与外部命令保持独立串行通道，避免替补并发发布恢复索引或启动多个命令。系统调用实际返回后收回配额，任务窗口显示各通道状态。

状态栏可打开保存冲突处理，比较共同保存基线、本地和磁盘内容。临时文档关闭时可保留恢复副本，最近 100 份保留内容可从文件菜单重新打开；损坏索引不会被当成空会话。编码、BOM 和插入换行规则与正文共同撤销。

“工具 → 文档比较”将当前文档快照与明确选择的文件放入独立只读双栏窗口。完整变更列表、上一个和下一个变更同步定位两侧范围；左右窗格分别显示原行号和变更颜色，空侧保留插入或删除锚点。垂直同步按两侧可滚动长度的比例移动，水平同步保持相同横向位置，两个方向可分别关闭。关闭窗口释放比较快照，原文档的正文、选区、编码、保存点与撤销历史保持原状。

比较按包含真实结束符的物理行求最少增删行数。NUL、前导 U+FEFF、CR/LF/CRLF、最后一行是否结束，以及规范等价但原始 UTF-8 不同的字符都参与精确比较；文件编码和 BOM 另行显示，正文相同不表示文件格式相同。单侧正文最多 8 MiB，两侧合计最多十万个物理行，每行连同结束符最多 256 KiB。求解及颜色准备共用五秒，求解另限六千四百万工作单位和四百万个回溯整数；超限明确拒绝整份比较，不截取或显示近似结果。可从工具菜单取消等待；源正文或视图在读取、计算期间改变后不发布旧结果。比较窗口呈现读取时的固定快照，不向源文件写回内容。

正文撤销和重做在后台准备当前仍保留的颜色，再一次发布正文、原选区、书签、颜色和历史；已清除的颜色不会从旧历史重现。编辑菜单可取消等待中的历史动作。等待期间正文、选区、权限、颜色、书签、视图、窗口、焦点或查找输入改变后不发布旧动作，权限或选区改走再改回也不恢复资格。准备失败保留正文与完整历史，查找等原生文字控件继续使用自己的撤销。

## 保存前备份

“Nate → 保存时备份设置”可选择关闭、保留上一份或保留多份，默认关闭。启用后，自动保存、立即保存、冲突确认写回及覆盖已有目标的另存为，先保存覆盖前的原始字节，再发布新文件。备份失败会停止原文件覆盖，并保留当前正文与独立恢复保护。新建目标没有旧内容可备份。

多份模式默认每路径 20 份、30 天、去重总容量 1 GiB，可分别调整。后续保存按期限、每路径数量和最近保留顺序清理历史；当前需要保护的旧原文件优先保留，无法容纳时停止覆盖。关闭备份保留已有历史。容量按索引引用的原字节去重计算，发布期间需要额外临时空间；异常记录保持现场，可能额外占用磁盘。

原始字节分块复制，全部强同步后才发布历史索引；相同内容复用已有文件，重复失败重试不反复写出相同历史。清理在新索引可靠发布后执行。备份保留原编码、BOM、NUL 和实际换行字节；它用于恢复正文，不归档原文件的 ACL 或扩展属性。索引最多 8 MB 和 65536 条，超过预算或配置无法解释时明确停止原文件写入。

“文件 → 打开保存前备份”提供路径筛选、时刻、大小和手动解码选项。选中的内容以独立文档打开，检查后可另存为；打开单份历史的字节预算为 1 GB。历史列表中的内容在打开时重新校验，过期条目或损坏字节不会被当成空文档。

## 使用

双击 `Nate.app`，可以拖入“应用程序”文件夹。日常运行不需要终端或 Swift 工具链。最低部署目标为 macOS 13；本机构建匹配当前 CPU 架构，采用本地 ad-hoc 签名。跨设备下载分发需要相应的 Developer ID 签名与公证。

| 临时查找下一处 / 上一处 | ⌘⌥E / ⌘⌥⇧E、Ctrl+Option+F3 / Ctrl+Option+Shift+F3 |

编码菜单区分“重新解释源字节”和“转换当前正文”。新文档默认 UTF-8 无 BOM，普通保存保留实际换行和末尾换行状态。打开文件不限制扩展名。

编辑器将 NUL 及其它会影响原生断段的行内控制字符显示为可见占位，后续正文仍可排版、选择和编辑。占位与原字符保持相同 UTF-16 长度，语法、颜色标记、鼠标命中和输入法坐标继续对应原文。占位仅用于显示，复制、保存、撤销与正文快照保留原始控制字符；Tab 保留正常制表排版。

## 功能与边界

“Nate → 设置”可选择系统等宽或已安装字体、7–72 点小数字号、跟随系统或浅深主题、自动换行和空白符号，并同步当前窗口的现有克隆；后来创建的克隆继承这些显示值。主题菜单同样保存选择，缩放保留字体家族；临时缩放不会因切换主题被重置。显示变化不修改正文、选择或撤销历史。缺失字体使用同字号系统等宽字体，原名称继续保留，可在设置中重新选择。

完整显示配置保存于偏好键 `editorDisplaySettings`，最多 8 KiB；没有完整归档时可读取原有字号、换行与符号偏好。损坏、未知格式或超量值保留原档并使用默认显示，表单显示原因；此时主题菜单只临时切换，明确应用完整设置后才重新保存。取消不写入，非法草稿可在原表单更正；等待期间偏好来源、偏好域或工作区关闭状态改变时，旧表单不能覆盖后来值。

设置可控制缩进参考线，并指定 1–4096 列的长行参考线；视图菜单可直接切换，长行线首次采用第 80 列，关闭再开启仍保留已配置列。缩进线默认开启，按照当前语言的实际 Tab 宽度落在完整缩进内部；空行最多参考前后二十行及同一正文已经确认的块开端，按语言采用向前或双向延续。只在逻辑行的首个视觉行显示缩进线，软换行不改变文件行号或补写空白。实际字形决定空格和 Tab 边缘，空行延续使用所属行的虚拟空格宽度；长行线采用默认正文字体的空格宽度，随缩放与文本方向改变。菜单和设置保存完整显示配置，同步现有克隆；单项菜单不重置临时缩放，未知归档只临时切换并保留原值。

参考线没有正文或选择修改权。每帧缩进规划共用 65536 个读取字节、4096 个来源行、4096 条参考线及八毫秒计算与定位预算，超限只暂停后续参考线并在状态栏说明；空行延续不超过距正文起点 100000 像素。屏幕外 ASCII 字形不逐项定位，没有可用排版时不估算参考线位置。参考线及其颜色不改变自动保存的修改识别，也不使原矩形选择的排版证据失效。

“Nate → 样式与主题”管理独立主题库，提供系统与原资源样式、内置明暗候选、新建、复制、命名、删除及逐项样式编辑。整体配色与通用语法类别分别编辑；语言目录保留原生数字类别和样式名称，UDL 采用自己的实际样式身份。前景、背景、字体名称、1–512 点整数字号、粗体、斜体和下划线可分别继承；明确关闭装饰与继承不同。缺失字体保留原名称并回退显示。只有“应用并关闭”保存完整库，取消丢弃草稿；切换主题不改变正文、选择、保存点和撤销历史，同一窗口的克隆、虚拟空间、打印与富文本输出采用对应来源主题。

主题采用稳定语言 ID 与原生编号，语言精确覆盖依次优先于精确词法身份、语言类别和通用类别；没有明确覆盖时保留原词法样式。UDL 自己的明确属性优先于通用类别，仍可通过语言精确样式另行覆盖。明确主题底色替代内置默认白底，专用语法背景继续保留；没有明确前景覆盖的内置文字按实际底色适配对比，用户明确选择的颜色保持原值。系统外观控制界面与继承色，不能重新解释已经固定的主题 RGB。

可导入独立 Nate JSON 或 Notepad++ 配色 XML，导出采用 Nate JSON。XML 的颜色选择、透明继承、字体与装饰转换为完整主题，未知语言保留定义；关键字文字不会改写语言词表，未映射的部件和字段在导入说明中逐项列出。链接悬停颜色用于前景或半透明背景提示，可在整体配色中编辑。导出不会覆盖当前工作区文件、它的硬链接别名或其它文件动作占用的目标；这不是 Notepad++ XML 的无损往返编辑器。

设置的“链接”页可关闭识别，或选择带下划线的前景提示、带下划线的背景提示、仅悬停前景、仅悬停背景。默认显示下划线，悬停时着色；双击真实链接字形交给系统默认应用打开，普通单击和带修饰键的选择保持原行为。识别和悬停不访问网络、不读取目标文件；输入法候选或编辑保护期间不打开链接。`file:` 目标必须通过本地文件 URL 校验，远程主机、凭据、端口和解码 NUL 均拒绝。

链接基础前缀为 `ftp://`、`http://`、`https://`、`mailto:`、`file://`；附加协议默认包含常见源码、聊天和系统应用协议，可用 ASCII 空白分隔修改。附加草稿最多 2048 UTF-8 字节、32 项，每项最多 64 字节，采用字母开头、后续字母数字或 `+.-` 的协议名及 `:` 或 `://`；重复或非法定义整份拒绝。仅修改链接不重置各克隆的临时缩放、布局和矩形选择。

链接页绑定文档实例、修订、不可变正文根及完整设置。每页只分析至多 64 KiB、128 个完整物理行和 4096 个候选，单目标最多 16 KiB；不截断长行或目标冒充完整链接。后台每批最多 128 行、256 KiB，使用共同五秒截止；视口只保留前 256 个可见物理行、最多 8192 像素范围的页。呈现共用每帧八毫秒计算与定位、4096 个矩形预算，超量暂停对应链接提示并反馈原因，正文继续编辑。目标由系统 URL 解析确认，无法表示的 URI 保持普通文字；自定义协议能否打开取决于本机已经安装的处理应用。

修改历史默认显示边栏和正文指示，区分未保存、已保存、撤回原文及撤回已有修改；同一行的多种类别并列显示，删除位置在空文件或文件末尾仍保留锚点。正文下划线及删除指示沿实际字形定位，不参与语法文字和选区修改。视图菜单及完整设置可关闭显示，重新开启不清除记录；“上一处修改／下一处修改”定位当前行之外的最近修改行，并展开遮挡的折叠。四类颜色及独立修改边栏背景可在主题中编辑，对应 Notepad++ 修改历史配色可导入。

修改分类沿唯一正文事务及撤销、重做身份推进；每秒原文件保存、另存为、冲突写回和重新载入分别确认真实保存点，保存副本不取得原保存点。后台保存先固定原快照，再完整重放期间的输入、撤销和分支编辑，后续文字不冒用旧写入的已保存类别；发布前复验正文修订及分类代次。保存不清空修改位置或撤销历史，分类更新只安排重绘，不重建排版或移动光标。

修改历史以连续字节区间和稀疏删除位置存储，每份日志最多 65536 个区间、65536 个删除位置及一百万项逆向记录，事务索引最多 65536 项和一百万个原字节动作。正文提交后的同步分类共用八毫秒线程实际计算预算及 250 毫秒经过时间上限，系统调度等待不消费线程计算额度；每帧绘制另有八毫秒计算与定位预算，最多 4096 个可见区间及删除位置。超量只暂停无法完整证明的分类或呈现并显示原因，正文、保存和唯一撤销历史保持。保存重放保留最近 4096 笔连续事务及一百万个动作，并携带尚未发布的全部已确认保存点；分类任务可由新写入取代，原文件自动保存不等待这项计算。后台保存分类短暂失败且完整时间线仍在时，可在后续保存重新核对；同步分类未得到完整结果、计算时钟不可用或连续保存事实超出证据窗口时，需要关闭重开文档重新建立分类。修改记录限于当前文档生命周期，不作为跨重启的正文恢复归档。

每份主题最多 8 MiB、512 种语言、每语言 512 项、全部 8192 个样式及 4 MiB 有效原字段；名称和样式身份最多 256 UTF-8 字节，颜色为 `#RRGGBB`。完整库最多 32 项、16384 个样式及 8 MiB 有效原字段，偏好键 `editorThemeLibrary` 的归档最多 16 MiB。JSON 重复键、未知字段与格式、非法值、超量、DTD 和外部实体整体拒绝。损坏偏好保留原值并采用系统显示，明确应用合法完整库后才重新保存。

导入文件可明确启用本地来源热更新，复制主题不会继承监视资格。已启用来源每两秒检查元数据，至少每三十秒核对完整摘要；合法完整新内容沿原主题身份和本地名称发布，无变化不重写偏好。文件不可读、损坏、读取期间变化、路径改向或偏好来源变化时保留当前有效主题并持续说明；路径改向需要重新导入确认。监视不写回导入文件、不取得正文保存权，也不发起网络请求。

“选中并查找”将实际选区或完整光标词保存为当前查询与查询历史，不显示查找窗口、不转移正文焦点；本次导航采用普通字面匹配，保留窗口其余模式和选项，大小写、整词与循环取自当前查找设置。“临时查找”不建立查找窗口、不改当前条件或任何输入历史，固定忽略大小写、允许子串并循环。两个动作均有正反方向和取消入口，没有选区时按完整光标词导航；到达无匹配边界时仍可显示该词的展开选择。

显式“选中并查找”遵守搜索输入设置中的填入标量上限，默认 1024，不受自动从选区填入开关影响；临时查找不使用自动填入阈值。所有快捷查询最多 1 MiB，光标词最多 262144 个标量，超限保留原查询与选区，不截断文本。取词与匹配在后台执行，完整保留 NUL、多行选择和原始 Unicode。多选与虚拟列拒绝作为一个查询；文档、修订、真实视图、选择、输入或焦点往返变化后，旧任务不能再移动光标。只读允许导航，候选、全文草稿和编辑保护期间不取得新导航权。

宏可录制两个快捷查找方式的前后方向，播放时读取实际选择或光标词。常规快捷查找使用当时的大小写、整词和循环选项，临时快捷查找保留当时的查询与历史。完整命中发布后才继续下一步，未命中、失效或取消时停在当前动作。

包含独立查找替换窗口、普通与扩展搜索、有预算的 Swift 正则执行器、多文档、目录与所选项目搜索替换、行排序与去重、空白转换、列数字、书签、宏、会话、文本摘要、结构化外部程序、打印、HTML/RTF 导出及离线 Markdown 预览。跨文件替换在确认后写入，并为未打开文件保留独立原字节副本。

“文件 → 打印设置”配置文档颜色、反色、黑字白纸或去背景方案，正文 25%–400% 缩放、原逻辑行号、FF 分页和毫米页边距。页眉与页脚分别具有左、中、右三栏原文、字体、6–72 点字号及粗斜体；变量按钮替换最近模板中的实际选择。支持 `$(FULL_CURRENT_PATH)`、`$(FILE_NAME)`、`$(CURRENT_DIRECTORY)`、`$(CURRENT_PRINTING_PAGE)`、`$(TOTAL_PRINTING_PAGES)`、`$(SHORT_DATE)`、`$(LONG_DATE)` 和 `$(TIME)`，`$$` 表示字面美元符。文件信息、日期时间和样式固定在作业开始时，变量内容不再次解释；日期时间采用当前系统区域与时区。未保存文档使用显示名称，目录为空。模板各区最多 4 KiB，完整展开各区最多 64 KiB；长内容限制在所属装饰区域，不覆盖相邻区域或正文。

“打印”与“打印选区”打开系统打印面板，提供预览、份数、页码范围、纸张、方向、缩放及系统 PDF 输出；选区入口只接受一个非空普通连续选择。“立即打印”明确使用当前系统打印机和既有纸张，不显示确认面板。只读允许打印，候选和文档保护期间拒绝启动，取消或失败不改变正文、选择、历史及保存状态。独立排版保留全部源范围，屏幕折叠与隐藏不删去打印文字；纸张或缩放变化重新分页。行号来自原逻辑行，软换行续行不增加源行号。黑白与反色作用于完整纸面，包括彩色字体，正文仍保留可选择文字。

“工具 → 导出 HTML／RTF”先固定当前正文、语法、字体和编码后的完整内容，再打开保存面板；面板期间改文、重命名或切换标签不改变本次输出。输入法候选、关闭及编辑暂停期间不打开面板，只读正文仍可导出。源范围最多 64 MiB，编码后的完整文件最多 256 MiB，超限整份拒绝。目标不能是工作区已打开或待连接的文件、其硬链接别名或其它任务占用的路径。写入复验磁盘基线并进入“工具 → 文件写入任务”，可在发布前取消；成功不改变原关联、保存点、选择或撤销历史。

启用 FF 分页时，行尾 FF 连同原结束符留在旧页，行首 FF 从新页开始；行内 FF 后的文字进入下一页。屏幕控制符显示打开时，FF 以可见符号打印；关闭 FF 分页不会由原生控件另行强制换页。单次独立打印源范围最多 64 MiB，最多一万页，完整原生分页每次最多十秒；源范围枚举与完整词法样式各有五秒预算。缺失字体、无法确认的词法状态、无效纸张或容量超限拒绝全部作业，不截断后打印。打印设置按完整格式保存在偏好键 `printSettings` 中；损坏、未知格式或超量归档保留原值并采用默认配置，设置表单显示原因，明确应用后才重新保存。等待期间配置或偏好域已改变的旧表单不能覆盖后来值。

“工具 → MIME 编解码”提供带填充、无填充、六十四列 LF 折行及逐行 Base64 编码，严格、逐行与显式保留分隔符的分段解码；Quoted-Printable 编解码；RFC 3986、RFC 1738、扩展和全部字节 URL 转义，以及后三种规则的逐行入口。URL 解码只展开一次百分号，字面 `+` 保持不变；Base64 拒绝非法填充、残缺组和非零尾位。Quoted-Printable 以最多七十六列的 CRLF 软折行传输，孤立 CR、LF、NUL 和尾随空白显式转义，解码保留原字节；行尾裸空白按传输规则移除。这些入口对应 [MIME Tools 的编解码功能](https://github.com/npp-plugins/mimetools)，正文输入按 UTF-8 原字节处理。

SAML 解码接收消息值本身，不含 `SAMLRequest=`、`SAMLResponse=` 或其它查询字段。依次执行 URL 与严格 Base64 解码，支持直接 XML、原始 DEFLATE、zlib 和 gzip 消息。压缩流必须完整结束且无尾随或拼接数据；XML 必须完整合法，不接受 DTD、实体声明、超过二百五十六层或一百万元素的结构，不访问网络。解码只还原消息，不验证签名、身份、受众和有效期。

“工具”的 MD5、SHA-1、SHA-256 与 SHA-512 摘要均提供直接输入、逐行独立输入、多文件及当前选区到剪贴板入口。文本按 UTF-8 原字节计算，不归一化 Unicode、不剥离正文 BOM 或 NUL、不改写换行；逐行排除实际 CR、LF 或 CRLF，连续与末尾空行独立保留。独立文本输入最多 64 MiB，逐行最多十万行，全部行共用五秒计算预算。结果保留全部算法，切换算法不重新读取已经变化的来源；明确点击“复制完整结果”才覆盖剪贴板。

多文件每次最多一千项，顺序流式读取磁盘全部原字节，不使用解码正文或未保存内容，也不受文本输入容量限制。读取前后复验描述符、路径身份、文件大小及修改时间；读取期间变化的文件不给出摘要，每项失败显示路径与原因。报告分别显示用户选择路径与实际读取路径，路径中的换行等字符转义显示；每个摘要只代表本次完整读取的固定字节。读取进度显示实际累计字节，取消或关闭窗口不发布部分批次。MD5 与 SHA-1 仅适合非对抗性的内容核对，四类裸摘要均不承担身份认证。

“字符与进制转换”提供字符、十进制、十六进制、八进制与二进制五个可编辑字段，均可完整复制或明确插入正文。数值保留 UInt32 的 0–4294967295 范围；字符按单个 Unicode 标量解释，代理项或超过 Unicode 范围的值仍可互转数字，但不能复制或插入字符。组合字符的各标量分别转换，不把一个字形误认作一个原始字节。数值只接受对应进制的 ASCII 数字，最多 64 个 UTF-8 字节，不自动去除空白、符号或前缀。插入绑定打开面板时的实际正文与选区，成功后保留正常撤销和输入宏；外部改变正文、选区或权限后须重新打开取得目标，只读仍允许计算和复制。

“ASCII / UTF-8 转 HEX”读取文本的完整 UTF-8 原字节；ASCII 字符直接对应其字节值，其它字符保留全部多字节序列。格式可配置 A–F 大小写、字节后空格及每行 0–4096 个原字节，0 表示不自动分行。完整行后按文档换行规则插入 CR、LF 或 CRLF，不再添加空格；启用间隔时，末尾未分行字节后也保留一个空格。“HEX 转文本 / 原字节”支持连续字节对，以及字节之间的 ASCII 空格、Tab、CR 和 LF；空白不能分开同一字节的两个数字，不接受 `0x` 前缀或非 ASCII 空白。非法或残缺输入整体拒绝；非 UTF-8 结果进入完整原字节窗口，不猜测字符集或覆盖源文本。格式偏好键为 `hexConversionOptions`，归档最多 4 KiB；未知或损坏值保留原档并提示默认规则，明确应用完整设置才保存，旧表单不能覆盖后来改变的偏好。这些工具对应 [Converter 的字符与原字节工作流](https://github.com/npp-plugins/converter)。

文本工具作用于一个普通连续选区，空光标表示全文；多目标、矩形和虚拟列不作为一个隐含输入。完整输入与输出各最多 64 MiB，转换、解压、结构检查和正文准备共用五秒预算；取消或任一阶段失败不发布部分内容。正文、选区、候选、权限、焦点或活动文档改变后，旧结果失去发布资格。可表示为 UTF-8 的结果以一次事务替换原范围并保留撤销来源；其它字节进入独立只读窗口，每页四 KiB，可按偏移访问全部结果并原样导出。导出不使用当前页的十六进制显示，不能覆盖当前工作区持有的文件或其它任务占用的目标。摘要可读取只读正文；等待时剪贴板已改变则只显示摘要，不覆盖后来复制的内容。

“编辑 → 行操作与排序 → 排序整行”提供字符序、忽略大小写、明确 macOS 语言地区规则、带符号整数片段、逗号小数、点号小数及行长度，各有升降序；另有反转、随机及完整参数表单。字符序按原 UTF-16 码元比较，行长度也按 UTF-16 码元计数，同键保留原行相对顺序。忽略大小写和区域排序使用 macOS 规则，区域菜单显示实际 locale，表单可另选语言地区；这些规则与普通查找的固定 Unicode 大小写折叠分别使用。

整数片段可超过机器整数范围，带 ASCII 负号的数字按有符号值比较，同数值的更多前导零在前，负零在非负零之前。小数读取空白、ASCII 数字、负号及指定分隔符构成的前缀，遇到其它字符停止；逗号转换为小数点，再按 binary64 比较。`1.2.3` 的点号键为 `1.2`，`1e6` 的键为 `1`，`+9` 或非数字开头按空键处理；只有空白的键升序在前、降序在后。无法转换的负号或分隔符、上溢与下溢会使整次排序失败，不保留部分行序。

选择集合为每项保留稳定身份、建立顺序和方向，并明确记录主选区。Command 点击追加并激活光标，点击已有空光标不重复追加；Command 拖动只延伸该项。状态栏、文本服务、候选锚点与导航读取主选区，Esc 收束到主选区。Option 拖动保留横向方向、真实零宽形态和各行的虚拟起点及选中尾部；短行空白只在插入时进入正文。正文事务的撤销与重做恢复完整选择状态，各分屏独立保存光标身份并按正文变更映射。

自动恢复、保留的关闭内容和命名会话均保存完整选择身份、主项、方向、虚拟列、矩形边缘、原生布局和逐行 Tab 证据。完整选择采用带 SHA-256 的紧凑归档，最多十万项和 6 MiB，清单仍受原有 8 MiB 总预算约束；只改变主项或形态也会在下个恢复周期保存，未改变状态不重复写入。载入先与实际正文校验，损坏的完整状态不能过滤成另一组选择，未知格式不会回退旧工作区后继续覆盖。旧式几何记录在合法边界重建身份，并在后续恢复周期保存完整状态。

命名会话只包含已命名文件的路径与元数据，不包含正文；临时文档由独立恢复存储保护。会话总量最多 8 MiB，保存和载入先成功确认输入法候选。原文件在会话保存后可能变化，完整选择无法用于当前正文时保留已打开内容和当前光标，并逐项显示原因。完整选择使用独立存储格式，不支持该格式的程序须保留记录并拒绝覆盖。分屏的独立运行视口仍由各视图持有，会话恢复当前文档状态。

“编辑 → 矩形扩展”及 Control＋Option＋Shift＋方向键可从单选择建立或继续扩展矩形。上下沿可见的真实逻辑行移动，折叠隐藏行不参与，软换行不增加文件行；左右每次移动当前字体的一个空格宽度，并将实际端点吸附到完整字形簇。矩形独立保留固定行、活动行与横向边缘，切换主项不改变活动边缘，收缩后反向延伸继续使用原固定行。正宽但未覆盖实际文字的部分仍保留形态；短行虚拟选中区域、光标与系统文本服务使用相同视觉位置，并纳入横向滚动范围。虚拟列输入法候选只在展示树中补空白，确认前的保存与正文历史不包含这些空格。

矩形同时记录实际字体、字号、方向、排版宽度、样式资源摘要和逐行字节及 Tab 边缘。字体、换行宽度或资源改变后保留原范围与身份，暂停按旧像素复制、剪切、粘贴、输入和查找，状态栏提示重新选择；精确恢复原布局后可继续。异步着色产生粗体等字形变化时，实际操作仍逐行复验，不能只凭资源标识相同继续修改。其它视图修改正文后，原矩形随完整修订链移动并保留身份，但须明确重选边缘；合并行也不会把部分 Tab 选择静默改成普通字节范围。正文撤销和重做仍可执行，并恢复原有完整形态。布局不适用导致候选确认失败时，最终候选保留，后续导航、保存或关闭继续等待成功确认或明确取消。

Tab 默认按当前字体的四个空格宽度停靠。矩形边缘位于 Tab 内部时，按该 Tab 实际字形字体的最近空格列确定输入和删除位置，只展开实际涉及的 Tab，保留未选中的两侧空白；选区背景、光标和系统文本服务使用同一视觉边缘。零宽矩形在 Tab 内前后删除一列，覆盖输入也只消耗一列；其它文字保持完整字形簇。全部行通过一个事务发布，撤销恢复原 Tab 字节和完整矩形。行末虚拟空间采用各行最后一个正文字符的实际样式字体；空行采用该行换行字符样式，文末空行采用默认样式。纯虚拟退格按固定行的一列重新投影其它行，保持同一薄矩形，不补空格、不制造正文修订或历史。Tab 内候选仅在展示树中保留两侧空白，确认后才形成正式输入。

输入与候选确认先准备全部目标，再一次发布正文与结果光标。系统指定的替换范围只替代主选区，其余明确选择仍参与输入；该临时范围不替换撤销所需的原选择。覆盖模式只消耗当前行内的完整字形簇，行尾及包含 CR、LF 或 CRLF 的输入按插入处理，保留后续正文与原换行；虚拟光标插入时补齐必要空白。相同文字覆盖只收束光标，不增加正文修订、撤销项或保存工作，也不清除已有重做。宏记录实际确认文字，不记录按各行生成的填充空格。一次输入原文最多 64 MiB，全部目标与填充合计最多 256 MiB，结果正文最多 1 GiB；先核对整批容量再分配空白，取消或超限保留原正文与选择。

剪贴板同时提供普通文本和 `org.nate.clipboard` 形态数据，保留原始 Unicode、NUL、片段建立顺序、独立主项、文档顺序、选择方向、矩形真实行数与虚拟边缘。普通文本按建立顺序连接；定位空白不复制，实际选中的虚拟尾部进入内容。等量多目标按源和目标文档顺序逐项粘贴，不等量时向每个目标插入完整普通文本。外部普通文本不被推测为矩形。无普通选区时默认只复制或剪切主光标所在整行，附加当前插入换行；编辑菜单可关闭此行为。

“Nate → 服务”把当前单一普通选区提供给用户选择的 macOS 纯文本服务。可写文档可在原选择或光标位置接收纯文本结果，操作可一次撤销。只读文档可以向服务提供所选原文。返回时会核对请求发起的文档、修订、焦点和选区，候选输入或状态已改变时保留原正文。

辅助功能可读取已提交正文的 UTF-16 范围、逻辑行及当前多选范围，定位完整字形并查询可见字形的屏幕坐标。实际焦点中的选区可以由辅助功能设置，获准的文字修改可撤销。纯文本服务和单次辅助功能读取或写入以 8 MiB 为限，较大的文档可按范围阅读。辅助功能一次最多交换 4096 项选择，列表首项为活动主选区。

在编辑区拖入 Finder 文件会通过当前窗口打开文件，一次最多 1024 项。拖入纯文本会在指针命中的正文位置插入，保留原始 Unicode、NUL 和换行，最多 64 MiB。一次撤销恢复拖入前的正文与完整选区。输入法候选未确认、文档只读或拖动来源变化时，保留当前正文。

矩形载荷向单个普通选择粘贴时，原选择先在临时正文中移除，再按真实块行处理；临时布局继承实际语言、用户语言字体、缩放、Tab、方向和换行宽度。可能改变字形的资源先在后台准备完整样式，纯颜色资源直接使用基础字形，准备与粘贴共用五秒截止；来源变化、取消或容量不足时不发布旧结果。矩形目标的全部选中行按同一事务替换；较短载荷不循环重复，较长载荷延伸后续真实行。空行、NUL 和最后空行保持，超出文档末尾按当前插入换行扩展；没有实际输入的空行不展开未选中 Tab 或补定位空格。完成后光标回到块起点，撤销恢复原正文、完整选择身份与矩形。普通多目标保持各自身份和插入后光标。

“粘贴换行适配当前文档”默认关闭，启用时仅转换本次插入内容，不转换原正文。“粘贴为纯文本”明确忽略私有形态；未知或损坏私有数据不会自动降级。候选未确认时剪贴板动作明确拒绝。复制、剪切与粘贴共用五秒处理截止，普通内容最多 64 MiB、私有表示最多 96 MiB、最多十万片段或真实行；全部粘贴与填充最多 256 MiB，结果正文最多 1 GiB。编辑菜单可取消准备，正文、选择、权限、焦点、字体、换行布局或剪贴板来源改变后不发布旧结果。剪切只有系统剪贴板写入成功后才删除正文。

剪贴板历史仅记录本应用复制、剪切及用户主动粘贴的完整载荷，不后台采集其它应用内容。编辑菜单打开独立历史面板，可查看形态和完整原文，切换 NUL、Tab、CR 与 LF 的可见表示，并按原形态粘贴到活动文档。最多二十条，单条文字、编码和片段索引的估计保留容量最多 1 MiB，总计最多 8 MiB；超大内容不进入历史，不截断记录。宏记录实际成功粘贴的载荷与换行选项，重放等待该事务成功后才继续。

“编辑 → 特殊粘贴与二进制”提供 HTML 源码、RTF 源码及二进制复制、剪切和粘贴。HTML／RTF 插入完整源码文本，不应用富文本样式、不渲染内容、不加载链接资源，也不改变文档格式。专用表示最多 64 MiB，解码与完整粘贴共用五秒截止；UTF-8 和 UTF-16 BOM 用作传输编码元数据。无 BOM 的原生 HTML 表示按严格 UTF-8 读取；RTF 只在最多 8 KiB 的根头部解释 `ansicpg`、ANSI、Mac 或 OEM 声明，正文、转义反斜杠、嵌套组和二进制块不改变全局代码页。合法 RTF 头部没有代码页时采用 Windows-1252；没有 RTF 头部的内容只按严格 UTF-8 读取。未知或冲突声明、非法编码和超量内容整份拒绝。

普通复制已经同时提供完整二进制形态；二进制复制和剪切沿同一实际成功通道，NUL、原始 Unicode、片段顺序和独立主项保持完整。二进制粘贴优先读取 `org.nate.clipboard`，未知或损坏时不降级；缺少该类型时只接受明确登记的 `public.data` 原始 UTF-8 字节，非法 UTF-8 不猜测为其它编码，普通外部文本也不因类型继承关系变成二进制。源码和二进制粘贴保留载荷原始换行，忽略普通粘贴的换行适配选项；成功后进入相同历史、宏和单次撤销。候选、只读权限、实际焦点、选择、代码页来源或系统剪贴板改变时拒绝旧准备，不截断或发布部分正文。

历史持久化默认关闭，此时不读取既有归档。在历史面板明确启用后，完整记录、稳定身份和精确时刻写入应用数据目录中的 `ClipboardHistory.dat`，归档最多 8 MiB，采用明确格式和整份 SHA-256 摘要。关闭持久化停止保存新内容，保留已有归档；清空历史同时顺序清空已保存记录。恢复期间的新复制优先，迟到读取不能恢复已明确清空的旧记录。未知格式、损坏、外部变化或保存确认失败保留原文件并停止自动覆盖；面板可明确选择重新保存，确认后仍复验完整磁盘基线。历史读写使用独立串行通道，选项等待当前文件动作完成；退出时归档尚未确认则保留运行状态，不把迟到写入当作已经保存。

输入法确认的全部目标通过事务门禁后才撤去候选。容量、字形或范围准备失败时，仍属于原正文和原选择的候选继续保留，可重试或用 Esc 取消；失败不产生正文、保存或宏输入事件。手动保存、切换、关闭、退出、只读角色、导航和克隆移除须先成功确认相关候选，失败时保持原文档和视图。自动保存继续保护此前已提交正文，候选内容不进入持久化快照。原正文、选择或编辑权限已经改变的组合失去提交资格，后续解除标记不会把它写入新来源。

宏播放先校验全部动作名称，再逐项等待输入、转换、排序、搜索替换与粘贴真实成功。失败、取消、文档切换或只读时停止，不执行后续动作；成功的相同字节输入仍可收束选择并继续下一步。每次最多一万项动作、重复次数为一至一万，完整一轮没有正文、选择或空命中继续状态的进展时结束重复。未知命令在任何正文修改前拒绝，并显示具体名称；载入宏不会自动执行。“宏 → 停止播放”收回后续步骤的执行权，已经完成的步骤保留并可撤销，后台任务返回前不允许启动另一项播放。每一步只接受上一项刚发布的正文与选择，焦点、权限或目标路径往返也会停止原宏，不能在新光标上继续旧动作。

宏文件保存完整输入、原生编辑意图、文本命令、排序参数、搜索状态和剪贴板载荷，采用明确二进制格式及整份 SHA-256，原始 Unicode、NUL、换行与动作顺序保持不变。保存与载入共用 8 MiB 和一万项动作预算，编码完成后才取得目标文件基线并写入，超量不会覆盖原文件；编解码与校验共用五秒处理预算。旧式 JSON 宏仍可载入，未知动作或字段明确拒绝，不忽略后继续执行。

临时录制最多一万项动作和 64 MiB 估计保留容量，完整文字与剪贴板片段索引都计入。下一项不能完整保留时停止录制，该项不会截断写入宏；已经完成的正文和此前动作保留，并显示具体原因。宏文件仍受 8 MiB 归档上限约束。未支持录制的菜单与原生按键命令持续显示在状态栏和宏管理面板，停止后仍可检查；新的录制或另一份临时配置清除上次提示。

方向移动、按词移动、逻辑行首尾与文档首尾定位、相应扩展选择、全选、保留主选区及前后删除使用同一原生语义入口录制和播放。删除按完整字形及 CRLF 边界提交，矩形删除只记录一项删除意图；失败不记录，不用固定光标坐标或空字符串替代动作。按词导航对全部选择共用十万字形预算，一项不能完整确定时保留全部选择并停止后续宏动作。

复制和剪切可录制当前选择语义及无选区整行规则。播放时读取当前目标的完整原文，沿同一原生形态与权限门禁写入系统剪贴板；剪切随后提交唯一删除事务，实际成功后才继续。录制中的整行规则独立于播放时的偏好，不改变视图设置。粘贴使用录制时确认的完整载荷和换行适配选项。复制或剪切失败、来源改变或取消时不执行后续宏动作；播放间隙新的剪贴板动作也会撤销原宏继续资格。

当前文档的前后查找、替换当前完整匹配和全部替换可录入宏，固定完整查找与替换原文、普通/扩展/正则模式、全部搜索选项及替换后停留规则。自动跟随的下一次查找不重复录制；只读跳过的替换不进入录制。播放使用录制条件，不改写当前查找窗口输入、历史或已保存设置。空命中保留独立继续证据，不反复选中同一起点；查找无命中、非法表达式、选区范围失效或后台证据改变时停止后续宏动作。全部替换沿录制规则使用当前连续选区或当前光标范围，拒绝多选、矩形和虚拟列被当作连续范围。搜索宏最多十万匹配与五百万计算步，完整动作详情显示真实范围选项和原文；其它搜索范围在录制时给出不录制说明。

“宏 → 运行至文档末尾”和命名宏面板的同名选项，在每轮完整动作之间检查主光标是否到达实际文末；开始时已在文末则不执行。正文、完整选择和空命中继续状态均无净进展时停止，包括移走又回到原选择的纯导航循环。文末模式最多一百万轮、一千万项动作及五分钟实际时间，达到任一预算明确停止，已完成步骤保留并可分别撤销；“停止播放”始终作用于同一真实任务。

“宏 → 命名宏管理”将已停止的临时录制保存为独立命令，可重命名、删除、导入、导出和分配快捷键。三栏面板显示定义、实际动作及完整只读详情，查看或载入不会执行正文操作；明确播放命名宏时保留当前临时录制。快捷键与现有菜单命令冲突时不启用，并显示原因；检查包含菜单大写键的隐式 Shift 和编辑器 Control 兼容入口，恢复的冲突绑定也保持停用。导入先完整验证，迟到结果不能覆盖已经改变的录制、文档、焦点或选择；导入预览仍可单独检查、保存和明确播放。未改变的导入定义按原始归档完整导出。

命名宏库最多一千项，名称和快捷键不得重复；整份归档最多 16 MiB，动作与归档的估计保留容量最多 64 MiB。独立串行通道保存到 `~/Library/Application Support/Nate/Macros`，先同步前一份完整列表，再发布当前列表；删除的定义同时从前一份列表移除，回退不会重新出现已删除项。损坏、未知格式或磁盘内容外部变化时保留现有文件与内存定义，停止自动覆盖，并显示只读或待保存状态。管理窗口的“重新保存当前列表”须明确确认，会以当前可见列表替换两份记录中的不可读内容；退出等待已开始的宏库保存实际返回。

“Nate → 快捷键映射器”按名称、菜单或稳定命令身份搜索实际命令，一个命令可添加、替换或删除最多十六个组合。清空绑定取消该命令的默认入口，恢复所选默认移除用户覆盖；全部恢复须明确确认。菜单、兼容按键、工具栏提示和捕获控件使用同一逻辑按键身份，包含隐式 Shift、方向键、功能键及带修饰的 Tab、Return、Enter 和 Backspace。Control 组合按应用映射执行，详情说明它对原生文本控件 Control 动作的覆盖；输入法候选、补全和明确快捷键捕获优先。系统输入源、Mission Control 等系统绑定仍优先，不注册全局键盘拦截。

映射导入先完整校验并展示预览，预览期间真实绑定保持原配置，只有“应用完整导入”才保存并生效。未改变的默认命令优先保留组合，冲突覆盖保持停用并显示所有者；不可用命令保留原身份与完整覆盖，不取得执行权。命名宏与运行配置的绑定分别只由对应管理面板保存，可从映射器定位具体定义；导入中的全局独立命令覆盖保留但不生效。导出保存完整用户覆盖，不将默认绑定展开为永久配置，也不执行任何命令。

用户映射保存到 `~/Library/Application Support/Nate/Keyboard/shortcuts.dat`，采用完整 SHA-256 的受限二进制归档，最多 1 MiB、两千项命令，编解码共用五秒预算。独立串行保存复验原文件基线和无链接专属目录；相同内容不重复改写。损坏或未知文件保留原字节并沿默认绑定只读运行；磁盘冲突时保留当前内存映射并显示尚未保存，停止后续自动覆盖。明确重新保存会先读取新基线并确认替换，超量文件仍拒绝读取或覆盖；退出等待已开始的实际保存返回。用户主动选择的导出文件仍沿普通文件保存规则处理。

普通单光标排序全文实际行，末尾换行产生的空位置不额外参与；一个连续选区排序涉及的整行。Option 拖选保留明确矩形形状，以实际选中列作键并移动整行；真实零宽矩形从各光标到行尾取键，正宽空键保持为空。普通多光标不被推测为矩形，未选中的折叠行保留原位。正文、光标、书签和当前仍保留的颜色通过一个完整事务移动，已清除的颜色不从历史重现。

结束符通常留在各物理行槽；空行移动将使独立 CR 与 LF 拼接时，重新分配原结束符以保留原字节总量和逻辑行数。所选范围边缘无法在原字节内保留行数时整体拒绝，可扩大范围或明确转换换行后执行。排序、正文和书签准备共用三十秒预算，最多十万行跨度、256 MiB 原范围、单键 1 MiB、累计 256 MiB 键；长度、反转和随机不复制整行键。颜色准备另受两秒与十万项结果预算约束。菜单可取消准备，正文、选择、权限、颜色、书签、窗口、视图、焦点或输入改变后拒绝旧计划。宏记录完整排序参数，播放等待实际成功后继续下一项，取消或失败时停止。

大量行的正文与结束符边界通过至多 64 KiB 的临时原字节分块顺序建立，普通整行键复用同行表；少量超长行直接沿持久化行索引定位。正文切片共享完整子树，只为保留的边界字节建立叶片，不构造随后丢弃的前后正文节点。跨分块 CRLF、末尾空行和原字节顺序分别确认后才准备完整重排事务。

“编辑 → 选择全部匹配／追加下一个匹配／跳过当前匹配／撤回最近选区”提供独立的匹配多选。单光标首次追加选择完整光标词，再次追加选择下一个尚未占用的匹配；到达末尾后循环，跳过只替换最后一项选择，没有其它匹配时保留原选择。撤回移除最近一项，始终保留至少一个光标；Esc 保留主选区并撤销等待中的匹配。大小写与整词选项独立保存，连续追加保留最初原文，Unicode 折叠后长短不同的命中不会改写下一轮查询。匹配与选择不改动正文、撤销历史、书签、查找原文或历史；随后输入对归并后的各段正文只提交一次，空光标位于非空选区起点时也不重复插入。只读允许选择，候选与编辑保护期间不执行；正文、窗口、视图、焦点、选区或条件往返变化均撤销旧计划。查询最多 1 MiB，完整光标词最多 262144 个标量，整轮共用五秒预算与十万个选区上限；全部匹配超量时整体拒绝，单次追加在首个可用命中后结束，可从编辑菜单取消等待中的计算。新追加目标会展开遮挡它的折叠区域，保留其它视图的光标。

列编辑器以独立字段提供固定文字、起始值、步长、重复次数、二／八／十／十六进制、无填充／前导零／前导空格、最小总宽度及十六进制字母大小写。起始值和步长按所选进制读取，重复次数与宽度使用十进制；填充模式下宽度 0 按本轮最长值对齐，负号计入宽度，补零放在负号之后。每个实际生成值受有符号 64 位整数范围限制，跨零序列正常生成。固定文字须非空、最多 1 MiB，通过“编辑全文”保留多行、NUL 和原始 Unicode。参数无效时保留原表单输入，上次明确参数在本次运行中保留。

明确选区按文档顺序替换并编号，交叠目标归并；同一原位置存在不同虚拟列时整体拒绝。单光标从当前字素列应用至末行，范围在确认前显示；完整字形簇计一列，Tab 使用四列停靠，短行只在插入时补空格。目标落在 Tab 内部时把该 Tab 按原停靠宽度拆分为空格，在确定列处插入；中文、组合文字和 Emoji 保留完整字形簇，原有混合换行继续保留。目标、数字、空白与正文树在后台共用五秒预算，最多十万项、256 MiB 输出和 1 GiB 最终正文；超限或取消不提交部分内容。编辑菜单可取消准备，正文、选区、真实视图、窗口、焦点、查询或保护状态变化后拒绝旧计划；有实际修改时正文和结果光标通过一个事务发布，撤销恢复原文及原选区。

普通与扩展搜索在忽略大小写时采用固定 Unicode 17.0.0 默认完整大小写折叠，覆盖 `ß` 与 `ss`、希腊字母的不同小写形式、连字及补充平面字母，不依赖系统地区。完整折叠允许长度变化，但命中两端必须落在原文完整标量边界：`ss` 可匹配整个 `ß`，`s` 不匹配其中一半。正反导航、计数、替换与字面高亮共用这一规则，返回原文的真实字节及 UTF-16 范围；不添加 NFC/NFD 归一化。整词边界与光标取词共同采用固定 Unicode 字母、标记、数字及下划线分类。区分大小写时按原标量精确匹配；正则保留其独立的 UTF-16 字符单位和大小写规则。

正则按分支和量词的实际优先级逐步回溯，找到完整成功路径后结束本轮；原子区域、占有量词和断言分别约束自己的回退范围。默认每次搜索限制为 500 万执行步、10 万回溯路径、100 万待执行节点及 256 层调用深度；嵌套区域共用路径和节点配额，字符类中的区间、大小写折叠和分类逐项计步，每 256 步检查实际取消和 3 秒截止。超限明确失败，查找与替换计划都不会把部分结果当作完整结果。

三种模式的完整查找输入均以 UTF-8 计量，最多 1 MiB，超过上限在读取正文前明确拒绝。正则编译另有限制：262144 个扫描步骤、128 层语法嵌套与 2 秒截止。目录 I/O 队列中的编译、字面查找、正则回溯和替换展开使用同一显式取消令牌，不依赖队列继承 Swift Task 上下文；已结束请求收回自己的句柄，旧请求不能清除新查询的取消入口。

查找、计数、逐次导航、当前选区复验和结构规则直接从正文树按需读取 UTF-16，不先建立整篇正文的 String 或 UTF-16 数组。每轮同步执行独立缓存最多八个叶片，每片最多 4096 个单元，常驻的派生正文单元最多 64 KiB。跨叶片断言、反向引用和回溯仍使用完整文档坐标；代理项两半保留原始匹配语义。共享准备对象只保存不可变修订证据，并发规则各自建立缓存，执行结束后释放缓存及其正文引用。

回溯控制支持 `(*FAIL)`、`(*F)`、`(*ACCEPT)`、`(*PRUNE)`、`(*SKIP)`、`(*COMMIT)` 和 `(*THEN)`。控制点约束当前回退候选及后续搜索起点；提前接受会关闭已经进入的捕获，子程序返回后恢复调用方捕获。普通断言、条件谓词和原子区域分别处理提前接受与控制边界。未知动词及动词命名参数在执行前报错。

分支重置捕获 `(?|...)` 的每个分支从同一编号继续，组后的捕获沿全部分支的最大编号分配。例如 `(?|(a)|(b)(c))(d)` 中，`ad` 的第二组未参与、第三组为 `d`；`bcd` 的前三组分别为 `b`、`c`、`d`。具名及数字反向引用读取当前成功路径的捕获，子程序调用使用该编号的首个定义。提前接受仍处理后续分支复用的编号；若因此形成反向捕获范围，整次搜索明确失败，不发布命中或替换计划。

字符单位转义 `\C` 与点号共用 UTF-16 单元及换行开关；`\X` 消费一个非组合单元和其后的连续组合单元，组合范围固定为 Boost 的 Windows 宽字符表，不随系统字形簇规则变化。组合后缀整体消费，内部不为后续条件回退；换行可作为 `\X` 的起始单元。起点及分支筛选保留组合单元表达式的原筛选规则，例如单独的 `\Xb` 与重复或原子分组形式可能有不同的候选起点。组合后缀和筛选前沿共用计算、取消、截止、路径与节点额度。匹配仍可能切开 UTF-16 代理项，这类结果可计数，但整份替换计划明确拒绝。正则的非 ASCII 词字符分类仍受系统差异影响。

数字反向引用支持 `\g1`、`\g-1`、`\k1` 及界定形式；相对子程序 `(?-1)`、`(?+1)` 按捕获声明位置计算目标。递归条件 `(?(R)...)`、`(?(R1)...)`、`(?(R&name)...)` 检查直接所属的当前调用，返回后恢复调用方上下文。引用中的零编号、相对子程序的零距离和不存在的调用目标在匹配前报错。

计数、标记、全部查找与全部替换采用批量继续规则：当前命中已经到达目标末端时结束，不再额外生成相邻尾部空命中；导航可在非空命中之后继续定位末尾空匹配。被拒绝的空匹配跨过标量或完整 CRLF，下一轮同步更新 `\G` 起点。替换前、后文本分别取自每轮真正的搜索起点和目标末端，目标之前的正文仍可供 Lookbehind 读取。匹配、捕获或替换上下文切开 UTF-16 代理项时拒绝生成替换计划。

逐次查找从当前视图的选区边界开始，找到首个匹配即停止；启用循环时，当前方向未命中才从另一端重新搜索全文。首次位于光标处的空匹配可见，同一视图、修订及条件下继续已选中的空匹配会前进。普通与扩展模式按实际反向顺序查找，正则默认禁止反向；单次替换只复验当前完整选区。用户移动光标、切换克隆或改变正文后，原导航结果失效。

增量查找栏位于编辑区上方，已确认输入逐次触发普通字面匹配；继续输入从本轮原光标细化，不跳过刚找到的词。Enter 与 Shift-Enter 前后导航，Esc 关闭并回到正文；栏所在窗口的匹配快捷键使用当前增量查询。大小写、全词、循环与全部高亮选项独立保存，全部高亮默认关闭。候选和全文草稿期间暂停定位，确认或取消后按完整原文继续；文档、视图或光标变化会撤销旧请求。长输入仍通过“编辑全文”处理，不截断表达式；增量定位不改动正文、撤销历史、书签及已有结果面板。

“全部高亮”使用当前真实视图的独立青色描边图层，不占用查找颜色与五组持久样式。开关只更新图层，不移动光标或焦点；导航仍可单独使用，并复用相同条件的完整高亮。输入连续变化时先取消旧任务，等待 80 ms 后在后台按完整字面查询匹配，NUL、符号与原始 Unicode 保留。全文匹配与索引共用五秒预算，最多十万项；超限不展示部分命中，独立状态说明原因，单个命中导航继续可用。持久与临时背景共享整帧 4096 项绘制预算，过密时保留完整索引并说明当前帧未全部绘制。

正文编辑后重新生成当前增量高亮，不自动选择命中；克隆焦点切换时清除原视图的增量图层，只给当前真实视图建立新索引。候选期间暂停使用已提交正文坐标，确认或取消后再匹配。关闭增量栏即撤销任务并清除该图层，用户持久标记和其它临时图层保留。正文、文档实例、完整输入身份、视图或保护状态改变后，迟到高亮不能发布；输入改动后恢复原文也不能复用旧请求。

选中文本智能高亮使用独立绿色描边，默认启用、忽略大小写并只接受完整词。没有选择时不从光标猜词；部分词、多选、虚拟列和跨行选择不会被缩短为另一表达式。关闭“仅完整词”后可匹配实际选中的单行短语与符号，始终使用字面原文并保留 NUL 与 Unicode 字节区别。搜索菜单提供启用、大小写、整词、复用查找窗口匹配选项和同时高亮另一视图五个开关；复用查找选项时独立偏好保留，菜单显示当前实际匹配方式。

智能高亮只扫描目标视口最多 400 个可见逻辑行，折叠隐藏区域不扩大为全文范围。拖选后等待 120 ms 再匹配，全文词定位最多 262144 个标量，选区原文最多 1 MiB；视口匹配与索引共用两秒预算、最多十万项。另一视图使用真实活动视图的选区表达式，并按自己的正文和滚动位置生成索引，不改动自己的光标。滚动、正文、来源视图、选区或设置身份变化后重新匹配；即使选区或设置恢复原值，旧任务也不能重新发布。候选与保护期间清除旧临时坐标，候选取消后重新读取已提交正文。只读正文可以高亮；智能图层不改变查询、历史、书签、持久颜色、增量图层或保存状态。

替换计划不复制全文的 UTF-16 投影，只读取格式实际引用的捕获和上下文。格式输入最多 1 MiB，单次原文引用和单项输出最多 64 MiB，全部替换输出合计最多 256 MiB，最终正文最多 1 GiB。原文读取、片段处理及中间输出共用 512 MiB 工作量和 500 万步预算，计划共用 5 秒截止并检查实际取消；嵌套分组和多个命中不能各自重新取得额度。任何限制触发都在正文提交前明确失败。

正则替换格式区分单数字 `\1` 与多数字 `$12`、`${12}`，支持八进制、十六进制、控制字符、命名捕获和匹配前后文别名。`$+` 取最高定义捕获号，`$^N` 取成功路径最后关闭的捕获；未参与组输出为空。括号界定条件范围，大小写状态跨括号延续；残缺与未知格式按 Boost 的相应字面规则处理。输出按 UTF-16 单元组合为合法 UTF-8，孤立代理项拒绝进入事务；非 ASCII 单元的大小写映射仍使用系统规则，尚未覆盖全部 Windows locale 差异。

批量缓冲区替换在开始发布前复验完整目标集合的对象、修订及保护状态，关闭后重新打开不能凭相同 UUID 和修订沿用旧权限；只读目标明确跳过。“全部打开文档替换”的确认绑定提示时的真实文档集合和正文，确认期间新增、重开或改写文档须重新执行。目录替换还固定原文件绑定，原打开缓冲区关闭或改绑后不会退回直接写盘通道。目录反馈分别列出已确认完成、未确认完成与未开始数量，发布后的同步错误保留具体阶段。

查找和替换条件按完整 UTF-8 原文复验，规范等价但编码不同的 Unicode 表达式属于不同请求。原文、模式、选项或范围改变时撤销旧计算和排队文件动作，改走再改回也不恢复旧请求；正常结束编辑及原文原样赋值保留未变条件的合法确认。目录查询还在计划发布、确认返回及每个后续文件开始前复验目录和过滤输入。所选项目定义变化前撤销对应搜索，未参与面板的装卸不影响原范围。已经取得发布权的文件动作仍按实际结果确认。正文分屏中的候选或搜索全文草稿开始时会撤销既有请求；取消输入后旧请求也不恢复发布权限。

结果导航绑定原文档实例和修订，关闭或重开后不会用原偏移重新打开同名文件。磁盘结果还复验基线与编码，未保存正文或不同解码方式需要重新搜索当前缓冲区。读取等待期间切换查询、结果区域、视图或光标会撤销旧导航；新输入法候选不会被迟到结果提交或丢弃。文件类型探测和读取使用有界 I/O 通道，返回后复验调用权，再激活目标并选中完整命中；迟到成功及错误都不能覆盖新界面。

底部搜索结果按“批次 → 文件 → 命中”分组，显示实际路径、行号、UTF-16 列号和带命中高亮的上下文；空匹配及跨换行匹配有可见标识。双击或 Enter 定位完整命中，上下命中按钮跨折叠分组连续导航。可展开、折叠、复制所选结果或完整路径，按批次、文件或命中删除展示条目及清空历史。Delete 与“删除所选”作用一致，选择分组时包含被筛选隐藏的后代，不改动源文件。路径复制保留完整原文，单元格摘要不参与定位或复制身份。

“每行一项”按匹配起始行合并同一文件内的展示条目，原始命中数、当前可见匹配数和展示项数分别计数；不同文件或批次互不合并。上下命中按钮仍逐个遍历完整匹配，同一行内移动时同步更新列号、上下文和高亮，Enter 与双击定位该项当前显示的匹配。合并项的复制和删除包含该项所代表的全部可见匹配，不影响被筛选排除的其他匹配。可随时切回逐匹配展示，两种显示方式使用同一份结果证据；显示偏好随搜索设置保存。

“更多 → 复制命中行”复制所选命中实际覆盖的完整源逻辑行，去除路径、行号和预览标记；没有选择时复制当前筛选可见的命中行。同一批次文件分组内按源行去重，跨行匹配覆盖的行全部包含，匹配终点恰在下一行起点时不额外包含下一行。原始 Unicode、制表符与 NUL 保留，源行之间统一使用 LF。内存来源复验原文档实例和修订，磁盘来源按搜索时的基线和编码重读，不打开文件标签或改用未保存缓冲区。后台构建共用五秒、十万行、64 MiB 输出及合计 1 GiB 磁盘原字节预算，超限、取消或过期不发布部分内容。结果选择、筛选或正文变化会撤销等待中的复制；发布前发现剪贴板已被更新时保留新内容。失败不会先清空剪贴板。

“更多 → 打开所选路径”只打开当前明确选中的可见文件路径，没有选择时不扩大到全部结果。按完整原始路径字节去重，一次最多二十个；超量或非法原始路径在文件探测前整体拒绝。已有文件沿用工作区缓冲区，尚未打开的文件读取当前磁盘内容，不使用旧搜索的偏移；因此搜索后内容变化的路径仍可显式打开，精确匹配跳转继续使用独立的过期检查。多个路径按结果顺序处理，结束后激活最后成功文件；改选结果、改变查询、移动光标、切换视图或窗口及退出都会撤销等待中的焦点交接，已经完成的标签保留。未命名文档和说明不伪造文件路径，只有路径的不可定位结果仍可打开对应文件。

结果筛选按原始路径和已显示上下文进行区分大小写的字面匹配，不重读源文件；完整筛选输入最多 16 KiB，后台计算共用五秒预算，候选或全文草稿期间保留上一完成视图。每批独立保存原查询、范围和实际匹配选项，标题提示及复制结果可查看选项。删除展示条目后原始命中数保持不变，并与当前显示项数分开。搜索历史在当前运行期最多保留二十批，合计十万原始匹配和 64 MiB UTF-8 元数据；无法无损定位的匹配同样计入数量。新查询需要空间时移除最旧批次并明确反馈，同时撤销其定位权。“清除旧结果”设置随搜索配置保存，只在后续完整查询成功发布时清除历史，失败或取消保留已有结果。隐藏结果保留历史，可从“视图 → 搜索结果”重新显示；工具输出使用独立视图，从“视图 → 工具输出”查看，正文和查找输入保持独立。

结果预览在后台生成，每个命中只读取附近最多 2048 字节，显示至多 500 个字符及真实行号、UTF-16 列号。路径和正文中的换行、控制字符与方向控制显示为转义文字，确保每个可点击结果始终对应一个原文范围。无法无损映射的 UTF-16 命中单独计数。一次查询跨文档共用 10 万命中、32 MiB 展示文本和 5 秒实际预览计算预算，取消或超限不发布部分结果；零命中清除原查询的可点击结果。

目录查询逐个读取文件，关闭文件的计划只保留基线、编码、替换意图与预览，不累积原字节和正文树。目录读取的单文件原字节上限为 1 GiB，超限文件明确列为未读取；整轮计划最多 10 万命中，替换文本合计最多 256 MiB。确认后逐个重读关闭文件，复验身份、全部原字节摘要和编码，再持久化原字节副本并按原基线发布目标；重读后发生的外部变化仍由发布门禁拒绝。打开文件使用原文档实例的可撤销事务；条件变化、取消或新打开同一目标时，未开始的文件保留原内容。

搜索书签在后台合并既有标记，整轮最多覆盖并保留 10 万行，构建共用 2 秒计算预算并检查实际取消。跨行命中在展开行区间前检查容量；UTF-16 半代理项单独反馈，不代替为邻近正文行。发布前复验文档实例、正文修订、查询条件及原书签身份，后台期间手动增删后即使恢复原集合，也不能重新授予旧计划发布权。搜索添加书签不修改正文、撤销历史或既有搜索结果。

搜索菜单提供切换、循环导航、清空、反转、复制、剪切、替换、删除书签行与删除非书签行。复制和剪切按文档顺序保留整行原始字节，包括原换行、NUL 以及无末尾换行；不添加分隔符。替换把整份剪贴板文本写入每个书签行的内容区域，保留原行结束符，书签仍落在该段插入内容的第一行。正文与结果书签通过一个事务发布，撤销和重做恢复相应集合。空末行没有可删除字节，删除只清除其书签，不生成空的正文历史。删除非书签行保留并映射幸存书签，不需要展开全部未标记行。

书签批量计划在后台共用五秒预算，最多十万项书签；复制和剪贴板输入最多 64 MiB，替换合计输出最多 256 MiB，替换后的正文最多 1 GiB。反转先检查结果容量，超限保留原集合。菜单可取消待执行行操作；正文、书签、视图、光标、查询或相关剪贴板身份变化时不发布旧计划。剪切先确认完整剪贴板写入成功，再删除原文。只读文档允许导航、复制及书签元数据动作，禁止正文行修改；编辑保护期间只允许读取和导航。候选输入期间的书签、折叠边栏点击不会确认候选或修改书签。

宏可记录书签切换、前后导航、清空和反转。每项作用于播放时的当前文档、主光标与书签集合。反转实际发布后才继续后一项，取消或权限变化会停止后续动作。完整一轮的进展判断包括书签集合，已录制的书签动作可随宏保存和重新载入。

宏也可记录跳到匹配括号、选择整对括号及内容、只选择括号内部。播放按当前正文、语言与主光标重新匹配。括号分析仍在后台时，宏等待原导航实际完成，缺少匹配或失去原视图资格会停止后续动作。

标记页的“标记全部”使用独立查找颜色，Enter 执行同一动作。默认保留旧查找标记，可选择每次成功后清除旧查找颜色，并可明确勾选同时给匹配涉及的全部逻辑行添加书签。失败或取消保留原颜色与书签。“清除查找标记”只清除颜色，书签继续保留；“添加匹配行书签”也可单独执行。颜色保留于当前文档生命周期，普通查询不清除它，不改变正文修订、保存状态、撤销历史、光标或结果批次。零长度匹配和仅包含换行的匹配在行内有可见指示，无法无损表示的 UTF-16 匹配明确计数。

“搜索 → 颜色标记”提供五组独立样式，分别使用黄色、绿色、蓝色、紫色和粉色背景。每组可标记当前选中文本的全部字面匹配，或只标记实际选区；没有选区时使用光标所在完整词，多选范围可同时添加到同一组。样式保留既有范围，不改写查找表达式、模式或历史。“样式匹配区分大小写”与“样式匹配仅全词”独立保存，默认忽略大小写并启用全词匹配。匹配表达式最多 1 MiB，光标词最多 262144 个标量；超限不截断文本或更改已有样式。

每组均有上一个、下一个、清除和复制入口。导航使用每个原始范围，嵌套与相邻匹配不会因为背景合并而被跳过；首尾循环，并在需要时展开正文折叠。“清除五组样式”保留查找颜色，“清除全部颜色标记”清除全部颜色组，书签始终独立。可分别复制单组、合并复制五组或全部颜色覆盖的文本；复制入口先核对实际编辑视图与活动文档，防止沿错误视图读取标记。只读文档可添加颜色，编辑保护期间可导航和复制，但不修改颜色集合。后台样式计划复验真实文档、正文修订、标记身份、视图、选区和独立配置身份，往返改变光标、查询或样式配置均不能重新授予旧计划发布权。

标记在插入边界之外保持原范围，内部插入扩张范围，部分删除缩小范围，完全替换或删除原正文时移除对应非空标记；空匹配使用后侧位置锚点。撤销和重做移动当前仍保留的标记，不从旧历史重新创建已经清除或消失的颜色。标记合计最多十万项，后台构建共用两秒预算。绘制合并同色交叠背景，保留每个原始匹配范围；整帧共用 4096 项绘制预算，密度超量时保留数据并在状态中说明部分背景未显示。预编辑期间不把已提交标记坐标直接用于候选正文，组合结束后恢复绘制。

“复制标记文本”复制实际颜色指示区，不复制路径、行号或预览摘要。同一颜色的重叠与相邻覆盖合并为连续片段，不同颜色的覆盖分别保留，包括重复正文；所有片段按原位置排序，同起点的短前缀在前。单片段不追加换行；多片段以 CRLF 分隔并补末尾 CRLF，任一片段含 CR 或 LF 时改用 `CRLF----CRLF` 分隔。片段内部的原有换行、Unicode 与 NUL 保持原样。空匹配不伪造正文，只有空匹配时保留剪贴板并反馈。复制最多十万项，正文与分隔符合计最多 64 MiB，后台共用五秒预算；原文档、修订、标记身份或剪贴板变化后不发布旧输出。编辑保护不禁止读取已标记正文，退出收束期间不再启动新复制。复制与清除动作不增加查找历史，表达式为空时也可使用。

计数与批量查找共用匹配顺序、空匹配推进、CRLF 和范围规则，只累计数量，不保存命中坐标、捕获或替换上下文，因此不受结果展示条目上限限制。实际扫描仍受普通模式的时间预算以及正则的共享执行预算约束；取消、错误和超限不显示部分数量。计数不修改正文、选区、书签、撤销历史或已有结果导航。

查找与替换字段保留完整原文；超过 2048 字节或包含换行、NUL 时显示字节数，通过“编辑全文”在可滚动多行窗口中查看和修改。Enter 插入换行，Command-Enter 确认，Esc 先交给输入法候选处理；取消保留原输入。历史菜单只绘制有界短标签，选择时恢复完整字节；规范等价但字节不同的表达式独立保留。执行不会使用展示摘要，旧全文草稿也不能覆盖已经改变的输入。

查找窗口的查找、替换、文件中查找、项目中查找和标记页分别显示适用动作；菜单和快捷键直接进入对应页签，切换时保留两个完整输入和既有选项。文件页显示目录、过滤和递归选项；项目页明确勾选可用面板；标记页添加命中行书签。可直接交换完整查找与替换内容，输入法候选确认前不执行交换。

查找、替换、目录和过滤条件各保留最近 30 条完整输入。历史菜单可使用原文、逐项删除或清空此字段历史，删除不会改写当前输入；键盘查找与按钮记录相同历史，取消任务不增加记录。历史身份独立于菜单位置，旧菜单操作不能误用重排后的条目。

搜索输入、历史、模式、选项和页签保存于 `~/Library/Application Support/Nate/Search.plist`。关闭面板、Esc、执行动作及改变选项都会提交当前配置，候选和全文草稿只保留上次已确认原文；后台顺序保存并合并尚未开始的请求，退出时等待配置写入。每类历史最多 30 项，当前输入和历史原文合计最多 16 MiB，归档最多 64 MiB；超限保留完整窗口内容和上一份归档，清理历史后可重新保存。损坏、未知格式、外部变化或保存失败不会自动覆盖现有归档；窗口的“重新保存设置”在确认后复验当前磁盘基线并写入完整当前配置。

“搜索输入设置”分别控制从选区填入、无选区时取光标单词、多行填入和“选区内”自动勾选。默认填入上限与自动勾选阈值均为 1024 个 Unicode 标量；emoji 计一个，组合标记、CR 和 LF 分别计数，字节数和 UTF-16 单元数不代替字符数。自动勾选阈值为 0 时保留手动状态；多选和虚拟列不开放连续选区范围。填入超限保留旧表达式，不使用部分选区或部分单词；巨大选区只判断阈值，不展开全文。改变设置不修改正文选区。默认单词由字母、数字、组合标记和下划线组成；关闭光标单词填入可保留既有查询。

“Nate → 词字符与边界”可在固定 Unicode 默认词字符上启用附加字符，关闭后保留原草稿。双击选词、按词移动、查找填入、快捷查找、普通与扩展整词匹配、增量与智能高亮、匹配多选、颜色标记及运行命令的当前词变量使用同一来源规则；正则自身的字符类保持独立。空格和 Tab 可明确加入，原始字符不解释为反斜杠转义。附加集合最多 256 个 Unicode 标量及 1024 UTF-8 字节，不接受 NUL、CR、LF、NEL 及 Unicode 行段分隔符。已有正文、选区和历史不被重写，完整取词仍有原有字符预算。

“Nate → 分隔符选择”配置一对原始字符和当前物理行或全文范围，默认行内圆括号。Command 双击或“搜索 → 选择配置分隔符内部”选择符号之间的正文，不依赖语言、语法样式或自动配对设置。不同符号按嵌套关系选择包含当前位置的最内层完整对；相同符号选择两侧最近的符号，双引号只要紧接反斜杠就跳过，不按反斜杠数量奇偶解释。直接点击相同分隔符时，两侧位置相同，按基线方向反选该符号。全文范围允许跨行；未找到完整对时保留原选择。

分隔符每端接受一个 Unicode 标量，不解释转义，不接受 NUL 或行段结束符。相对单字节分隔符规则，Unicode 字符和正文中 NUL 后的继续匹配属于增强行为，组合字符序列不能作为单端配置。选择在后台扫描完整快照，最多 64 MiB、262144 层未闭合嵌套及五秒；超限不返回部分选择。原正文、选区、焦点、候选、保护或规则来源改变后不发布旧结果。偏好按完整归档保存并同步克隆，损坏或未知格式保留原归档并采用默认规则；取消表单不写入。

“Nate → 文件与新建默认设置”配置新建文档的内置语言或已载入 UDL、LF/CRLF/CR 换行、最近文件数量、文件对话框的起始目录，以及 Finder 打开文件时的窗口。Finder 默认复用当前窗口，也可以为每次打开的一组路径创建一扇窗口。已打开文件仍按实际文件身份使用同一份正文与保存通道。

新建文档使用 UTF-8 无 BOM，已有文档的正文、格式、选区和撤销历史不随偏好改变。默认语言资源暂时缺席时，新文档采用纯文本并保留原选择。起始目录可采用上次选择、当前文件父目录或自定义绝对路径，当前文档未命名时回退上次位置。

最近文件可设为 0–200 条，默认 30 条；0 停用显示与新记录，已有历史保留。规范等价但原字节不同的路径分别保留，损坏历史不被新文件记录覆盖，明确“清空历史”可重建空历史。语言身份和自定义路径各限 8 KiB，完整文件偏好归档限 128 KiB；损坏或未知格式保持原数据并采用默认值，只有明确应用才保存完整设置，过期表单不能覆盖后来配置。

“Nate → 搜索引擎”配置 Google、DuckDuckGo、Yahoo、Stack Overflow 或自定义 HTTP(S) 模板；兼容 Bing 选择项使用 DuckDuckGo，菜单和预览明确展示实际目标。编辑菜单和正文右键的“搜索选区或当前词”只在明确执行时交给默认浏览器，不改动正文、选区、历史或查找条件；预览使用固定示例，不读取正文或联网。没有选区时采用当前词边界配置，矩形、多选区、未确认输入或缺少真实正文焦点时不发送查询。网络搜索不录入宏。

自定义模板最多 4 KiB，支持 1–16 个 `$(CURRENT_WORD)`，变量只能出现在固定主机之后，不能包含凭据或其它运行变量。空白、控制字符与字面百分号须按 URL 规则编码。查询最多 16 KiB，按原始 UTF-8 字节进行百分号编码，保留组合字符、NUL、换行和变量外观，不二次展开；最终网址最多 64 KiB，超限拒绝完整动作。偏好归档最多 32 KiB；损坏或未知格式保留原数据，停止网络搜索，直到用户明确确认并保存有效引擎。取消或过期表单不保存，切换引擎保留自定义草稿。

“Nate → 导出用户配置”把当前支持的完整偏好保存为独立 `.nateconfig` 文件，涵盖字体与外观选择、Tab 与缩进、配对与词规则、显示与补全、搜索行为与输入字体、默认文件入口、搜索引擎、打印、HEX 与保存备份策略。“导入用户配置”完整读取后先显示逐项差异，明确确认才一次应用整份偏好并同步现有克隆视图。原文、编码、换行格式、选区、保存点与撤销历史保持原状，新建默认设置只影响以后新建的文档。

用户配置不携带查询与替换原文、搜索和最近文件历史、剪贴板内容、窗口位置、恢复数据、主题资源、UDL、快捷键、宏或运行命令；这些内容各自独立管理。搜索行为使用偏好键 `searchUserPreferences`，与 `Search.plist` 中的原文和历史分别保存，重启时合并行为选择。配置中的网址和目录只作为偏好值展示，导入不会打开网页、访问目录或执行命令。

配置文件最多 4 MiB，含完整 SHA-256 摘要、明确字段类型和规范键序。已知的完整旧配置沿用当前恢复存储总量和标签切换顺序中尚未提供的设置。其它字段缺失、未知字段或格式、非法参数、重复 JSON 键、截断与摘要不符均拒绝整份导入。取消、候选输入未完成、关闭工作区，或读取与预览期间当前偏好及来源发生变化时，不发布旧候选。界面同步失败会恢复原偏好域。损坏配置保留原始数据并说明原因，编辑器仍可打开。导出固定当前快照，通过目标基线与工作区占用检查后原子保存。活动文档、硬链接别名或其它文件动作持有的目标不可被配置导出覆盖。菜单中的“取消配置读写”撤销尚未发布的动作，已完成的文件保留。

“Nate → 日期时间格式”提供原格式编辑和固定时刻的实时预览；编辑菜单分别插入短日期时间、长日期时间和自定义日期时间。默认自定义格式为 `yyyy-MM-dd HH:mm:ss`。短长格式采用 macOS 地区、日历和时区的短时间，默认先时间后日期，可切换为先日期后时间；长日期包含完整星期与日期。一次动作的全部光标使用同一时刻和文字，遵守普通多光标、矩形、覆盖及撤销规则。宏记录实际生成的输入文字，播放不重新读取时钟。

自定义格式的字段采用 [日期字段](https://learn.microsoft.com/en-us/windows/win32/api/datetimeapi/nf-datetimeapi-getdateformatex)与[时间字段](https://learn.microsoft.com/en-us/windows/win32/api/datetimeapi/nf-datetimeapi-gettimeformatex)的大小写含义：`d/dd` 为日数，`ddd/dddd` 为星期，`M/MM` 为月数，`MMM/MMMM` 为月名，`y/yy` 为两位年份，`yyy` 及更长为至少四位完整年份；`g/gg` 为纪元；`h/hh` 与 `H/HH` 分别为十二与二十四小时，`m/mm` 为分，`s/ss` 为秒，`t/tt` 为上午下午首字符或完整名称。日月字段最多按四次重复解释，时间数值最多两次；数字使用 ASCII，名称采用本次固定的 macOS 地区及日历，跨系统地区文本可能不同。带数值日字段的月名采用日期上下文，其它月名采用独立名称。

单引号包围字面文字，两个连续单引号输出一个单引号，其它非字段字符原样保留；例如 `'生成于 'yyyy-MM-dd HH:mm:ss`。格式只解析一次，展开文字保持原样。格式最多 256 个 UTF-16 单元和 1024 UTF-8 字节，拒绝空格式、未闭合引号、控制字符及行段结束符；完整输出最多 16 KiB。格式化失败不会以空串覆盖原选择。偏好归档损坏或未知时保留原字节并使用默认格式，取消表单或来源改变不覆盖当前配置。

日期时间转换接受公历 1 年至 9999 年的有限绝对时刻，本地日历年份须位于 1 至 99999；时区转换后超出这一区间时拒绝输出。自定义格式的连续 `t` 只区分一次与两次以上，后者输出一个完整上午下午名称。

偏好键 `wordBoundarySettings` 保存最多 4 KiB 的完整规则；损坏、未知或超量归档保留原值并采用默认分类，明确应用完整表单后才保存。表单取消不写入，来源改变或工作区关闭后不发布旧草稿。规则变化撤销旧取词、高亮和导航资格，改回相同字符也不恢复旧运行变量预览的执行权；每个搜索请求和录制宏固定自己的词规则，旧归档缺少该字段时使用默认分类。

“输入字体”为四类搜索输入和“编辑全文”设置独立字体，默认 Menlo、13 点，支持 7–32 点及小数字号。窗口最小高度随字体行高和当前页签调整；字号改变不改写原文、候选或全文草稿，正文视图保留自己的字体与缩放。字体设置随搜索配置保存，缺失字体使用同字号系统等宽字体并显示原因，仍保留所选字体名称。

补全合并文档单词、语言关键字和函数资源，参数提示可切换重载；自动触发、字符阈值、Tab 和 Enter 确认可分别配置。手动路径补全只在明确请求时枚举目录。单词补全采用“词字符与边界”的设置，并保留当前语言补全表的附加字符。候选最多 200 项，文档单词扫描取光标周边至多 16 MiB，只收录两端完整、来自光标以外位置的词。前缀超过 4096 字节时暂停该词的候选，适用的函数参数提示仍然可用。

“Nate → 补全与参数提示”可独立启用输入后的候选和函数参数提示，两项默认开启。此前保存的自动补全偏好继续适用于参数提示，直到单独配置。编辑菜单可随时手动请求候选或参数提示。

“语言 → 当前语言的补全 XML”可导入、编辑、导出、重新载入和恢复随包定义。定义应用到选定的语言，包括纯文本和 UDL。采用 Notepad++ 的 `NotepadPlus / AutoComplete` 格式，支持独立词字符、函数与重载。导入会替换该语言的词表和参数提示定义，文档词和语法关键字仍按原补全设置提供。导出保留原始 XML 字节，包含用于其它编辑器的 `terminal` 属性。Nate 的参数提示采用 `startFunc`、`stopFunc` 和 `paramSeparator`，各为一个完整字符。 [Notepad++ 补全 XML 格式](https://github.com/notepad-plus-plus/npp-usermanual/blob/master/content/docs/auto-completion.md)

每份用户补全最多 1 MiB，当前有效用户定义最多 128 份且合计不超过 16 MiB。XML 校验禁止 DTD 和外部实体。应用确认磁盘原文件并安全写入后才启用整份定义，同时撤销旧候选和参数提示。校验失败或文件被外部改写时保留当前有效定义，通过“重新载入用户补全”可再次校验磁盘内容。

Tab 与 Enter 的确认设置同时应用于普通候选和手动路径候选。关闭其中一个确认键后，该键按编辑器当前设置执行缩进或换行。数字键盘 Enter 沿用同一 Enter 设置。

手动路径补全读取当前一级目录，最多检查 20,000 个条目，枚举和排序共用五秒预算。路径确认保留已输入的父路径和引用边界，已有的相对路径、重复斜线与 Unicode 原字节保持。包含 NUL 或超过 64 KiB 的同一行前缀无法作为完整路径分析，候选窗口会说明扫描上限。

内置语言的函数参数提示使用实际词法范围。注释和字面内部的标点不参与参数计数，输入尚未闭合的字符串时可保持外层真实调用的提示。在同一调用内继续输入参数时保留选中的签名；移到另一处调用时从第一项开始。调用上下文最多取光标前 64 KiB，词法状态不足或超出预算时暂停提示。

普通 Return 和数字键盘 Enter 都遵守 Enter 确认设置。关闭确认或候选为空时执行正常换行。正文中的 Ctrl+Return 与 Ctrl+Enter 手动请求文档单词，无需达到自动触发阈值，已出现的候选也由本次手动请求重新计算。

候选属于原正文、窗口、光标和语言规则。切换焦点、修改选择、进入输入法组合或改变文档权限后，需要按当前上下文重新请求。手动路径补全还绑定文档的实际磁盘目录，改绑后旧路径候选失效。

宏可录制已确认的补全，保存实际替换的前缀及用户选中的完整原文。播放核对当前光标之前的前缀字节，并执行同一个替换事务。前缀不匹配时停止后续动作，重放无需重新查询候选或访问目录。

“视图 → 函数列表”使用独立 XML 规则提取名称、排除注释并组织类与方法，支持筛选、源码顺序、名称排序及双击或回车定位。没有规则或表达式无法完成时显示具体原因。解析在后台运行，正文超过 64 MB 或计算超过预算时停止；切换文档、语言或正文修订会撤销旧导航范围。

“语言 → 当前语言的函数列表 XML”提供独立的导入、编辑、导出、重新载入和恢复当前关联。可为内置语言、纯文本或 UDL 指定函数、类及方法的识别规则。规则固定到打开表单时的语言，导出保留原始 XML。全部表达式通过校验后才保存，磁盘内容改写或表单过期时保留当前规则。规则生效后撤销相同语言各窗口的旧导航范围，活动面板立即重新提取。每份用户 XML 最多 1 MiB，有效定义最多 128 份且合计不超过 16 MiB。

“语言 → 函数列表关联”可导入、编辑、导出及恢复 `overrideMap.xml`。关联使用 Notepad++ 的固定 `langID` 或 UDL 原名称，一份规则可以供多种语言使用。导入时只读取明确引用的同目录 XML，缺席的文件可以使用同名随包规则。关联与规则一起校验和保存，引用缺失、文件改向或表达式无效时保留此前生效的映射。映射最多 1 MiB、256 条，引用规则最多 128 份，每份不超过 1 MiB、合计不超过 16 MiB。当前语言单独保存的 XML 优先，其次是用户关联，最后使用随包默认规则。导出的关联 XML 保留原字节；各关联规则可通过当前语言的函数列表菜单另行导出。

函数列表的点号默认匹配换行，可在表达式中用 `(?-s)` 关闭。名称子规则按原顺序逐层收窄实际命中范围。用户定义在校验时拒绝后行断言，Lua 和 Visual Basic 的随包规则保留原有的固定长度后行断言。全部表达式共享一次后台执行预算。 [Notepad++ 函数列表规则](https://github.com/notepad-plus-plus/npp-usermanual/blob/master/content/docs/function-list.md)

其它原生段落的完整输入预算为每逻辑行 1 MiB。超过时在该行与状态栏明确暂停字形呈现，保留完整正文、历史及保存能力。缓存同时限制为 256 行与 1048576 个呈现 UTF-16 单元；原生布局规则参与持久矩形的样式身份，规则改变须重新确认视觉边缘。

内嵌 JavaScript 的花括号、模板表达式和块注释可以在 HTML 文件中独立折叠。已确认的脚本类型包括默认 JavaScript、模块及明示的 JavaScript MIME 类型。数据脚本与带 `src` 的元素采用整段范围，脚本范围由真实 HTML 标签界定。标签属性确认最多读取 64 KiB，代码与标记共用折叠预算。

HTML 的 script、style、title、textarea 及其它原始文本区域不把内容中的标签外观作为补全目标；遇到 script 双重转义时，本次前缀扫描保持后续区域为字面输入并显示说明。闭合识别不执行脚本、不展开实体、不读取外部 DTD，也不作为整份文档的有效性校验。单次输入最多读取目标之前 64 MiB 原文，采用 8192 字节块传播状态；标签和属性名称各最多 4096 字节，超量目标保留 `>` 并显示原因。全部目标共享五秒截止、256 MiB 输出及 1 GiB 最终正文预算，来源或执行资格失效时不发布部分目标。标签输入按当前语言录制为独立语义宏，播放时不依赖自动闭合偏好开关；普通原字节宏、候选确认、明确系统替换、覆盖模式与矩形输入保留原通道。

缩进退格由全部目标共用 1 MiB 读取额度、百万逻辑列上限与五秒截止，任一目标超限则不提交部分删除；没有前导缩进时沿标准字形边界处理。配置改变只作用于后续按键，并同步当前及新建克隆，保留已有正文、选择与历史。偏好键 `indentationSettings` 保存 `automatic`（`disabled`、`inherit` 或 `language`）和 `backspaceUnindents` 的完整规则，归档最多 1 KiB；损坏值、未知格式和未知模式保留原档并说明默认行为。只在明确应用且原偏好来源仍有效时保存，取消及过期表单不写入。

普通 Backspace 与 Delete 使用固定完整选择准备事务，删除区间按文档顺序归并，结果按原选择建立顺序保留存活身份及明确主项。重叠目标只删除一次原文字节，撤销恢复操作前完整选择；纯虚拟退格只改变列元数据，不生成正文空格。

屏幕排版、Tab 与空格转换、增加或减少缩进、列编辑、运行命令列号、打印与富文本导出共用明确 Tab 宽度。克隆视图按各自真实文档的语言解析规则。列宽变化保留矩形身份和原范围，但暂停旧视觉边缘的修改资格；后台列任务与命令预览即使遇到配置往返也须重新取得来源。逻辑列读取最多一百万步、一百万列并共用至多五秒的截止，不能完整证明时保留全部正文和选择，不截取前缀估计。

偏好键 `languageTabSettings` 保存完整默认与最多 512 个语言覆盖项，归档最多 512 KiB。未知语言的合法覆盖项继续保留；未知格式、损坏值或超量归档保持原值并明确使用默认设置，只有明确应用完整配置才重新保存。设置表单固定打开时的语言与偏好来源，取消不写入，等待期间配置变化则拒绝旧表单覆盖。

语法呈现最多保留 256 行样式和 4096 个检查点，单行最多 1 MB，视口最多 262144 个词法片段。Python 额外限制为每行 65536 个片段和 64 层插值；单引号续行依据同一快照的后续终止证据确定样式，确认过程服从单行 1 MB、正文 64 MB 和所属任务 5 秒的预算。超限保留正文和明确状态，同一失败视口不会因重绘反复解析；转到可完整解析的位置后继续着色。打印和富文本导出在词法状态无法完整确认时拒绝生成部分样式输出。

UDL 可以导入、导出、克隆及编辑原始 XML；无效规则不会替换正在使用的定义。各样式的前景、背景、粗体、斜体与下划线分别保留，编辑区和独立输出共用来源样式。八组关键字、前缀、注释、分隔符与运算符采用最长字面匹配，同长保留原定义顺序；ASCII 规则复用前缀索引，忽略大小写的非 ASCII 规则保留完整原字节长度的小写比较。

彩色打印和 HTML／RTF 导出固定来源视图的实际 UDL 与外观，保留多行注释、跨行短语、分隔符及字体装饰。选区之前只传播词法上下文，输出中只包含明确源范围；已准备的打印内容不随后来规则变化重新解释。完整样式传播最多 1048576 行、合计 64 MiB、单行 1 MiB 和 1048576 个片段，共用五秒截止；缺少用户语言、取消或任一限制触发时整份拒绝，不生成部分样式。黑白打印沿用明确的纯文本方案。

普通关键字和 `Operators2` 只从真实空白或已识别前向符号建立的起点匹配整词；普通点号、冒号和 NUL 不自行分词。文件末尾不代替结束证据。前缀模式覆盖匹配词的完整原范围，例如 `alpha` 可使 `alphaTail` 或 `alpha.name` 整词着色；关闭前缀时二者均不会截取开头。整词运算符优先于整词折叠和关键字，前向运算符及普通代码中的前向折叠保留自己的优先职责。关键字中的 `((literal phrase))` 按固定空白字面匹配属于 Nate 的增强行为，不与引号短语的可变空白混用。

八组关键字、`Operators2`、`Folders in code2` 和 `Folders in comment` 可使用引号短语：双引号内的间隔匹配 ASCII 控制空白、空格及真实换行，单引号内的间隔只匹配空格和 Tab；NUL 不作为空白。声明中的反斜杠可转义引号和反斜杠。短语须取得真实空白或前向结束外观，文件末尾不虚构结束符。关键字的前缀选项在短语后存在空白时还包括下一完整词，其空白类别继承最后一个短语间隔；单引号前缀遇到换行时仍沿用这一类别。整词运算符、代码折叠、注释折叠和八组关键字按此顺序取得匹配资格。

短语内部已识别的前向分隔符动作在短语着色后执行，后续文字继续使用该动作建立或结束的上下文。跨行范围只复用同一文档、修订及不可变正文根的证据，后续片段必须连续；正文或规则改变后重新确认。短语分析限正文 64 MiB、单次向后取证 1 MiB，并共享词法扫描预算；超量或来源不一致时拒绝本次完整结果。短语折叠按实际物理行建立：开端与分支从短语首行开始，闭合短语的全部行属于当前块；不沿用原始 LexUser 在跨行或部分短语后偏移层级行号的行为。

导入完成后按语言显示可滚动、选择和复制的完整兼容说明；UDL 编辑窗口也在 XML 旁保留逐项说明。未知元素、属性、规则组、样式和未应用的嵌套位都会保留原 XML 并报告实际字段路径。`darkModeTheme` 保留为来源信息，用户语言颜色按当前 macOS 外观呈现，不自动成对切换。新建定义默认继承当前主题颜色与字体。

`fontName` 按本机字体名称解析，未指定或不可用时继承编辑器字体家族；`fontSize` 独立采用 1–512 的整数点数，空值、`0` 与 `-1` 继承编辑器字号。名称最多 256 UTF-8 字节且不含控制符，非法字号或名称拒绝整份定义。粗体、斜体和下划线独立生效，屏幕、彩色打印与富文本导出共用字体呈现；实际逻辑行高度容纳有效样式的最大原生字形，未知样式不改变排版。

视图放大或缩小按相同点数调整基础字体与资源显式字号，不重复缩放继承字号；基础视图字号限定为 7–72 点，各资源呈现至少为 1 点。重置恢复本次显示配置的基础字号和原资源点数，明确应用显示设置会建立新的缩放基准。新分屏继承当前差值，之后可独立调整；新打印或导出采用实际来源差值，已准备的打印内容保持原字体。

已知字段须位于对应容器，扩展子树中的同名节点不取得配置权限，也不向关键字列表添加文字。布尔字段只接受 `yes`／`no`，`colorStyle` 只接受 `0` 至 `3`。单份资源最多 256 个语言定义，节点名称与属性名最多 256 UTF-8 字节，每个节点最多 128 个属性；兼容说明合计最多 4096 项、512 KiB，多语言共享说明展开后仍遵守同一总量。超量或非法字段整体拒绝，原有效配置保持可用。编辑 XML 后清除旧说明，后台完成结果只有在原始输入字节仍一致时才更新当前窗口状态。

`Comments` 与 `Delimiters` 的编号必须是两个 ASCII 数字，分别限于 `00` 至 `04` 和 `00` 至 `23`；带正负号、其它数字外观或未知编号不会成为有效规则，并逐项显示原字段位置。只有编号而没有正文的项目作为空占位保留。编号后的 Unicode 标量及组合标记按完整 UTF-8 保存；超过原始 LexUser 字符范围的规则明确标为 Nate 增强行为，不宣称原编辑器也采用相同匹配。

UDL XML 输入限 4 MiB 严格 UTF-8，禁止 DTD、实体声明和外部资源解析。正文中的 U+FEFF 与合法数值字符引用保留原标量，CDATA 内的引用写法保持字面文字；文件起始的 UTF-8 BOM 只作为编码标记。解析前的可逆字符保护副本最多 8 MiB，保护字符不足时整体拒绝；用于导出和编辑的原始 XML 始终保留原字节。

`Global` 的 `forcePureLC` 决定行注释位置：`0` 为任意位置，`1` 为严格物理行首，`2` 为该行此前只有 ASCII 空格或控制空白。NUL 与非 ASCII 原字节算作已有内容；每个真实 CR、LF 或 CRLF 后重新确认位置。非法选项拒绝整份定义，规则切换撤销旧语法与视觉动作的权限。

`Comments` 的 `00` 编号定义行注释开端，`01` 定义紧邻真实结束符的续行标记，`02` 定义可提前闭合的字面标记。续行按完整标记与当前大小写规则判断，尾随空格或额外正文会结束续行资格；标记本身也保留原字节。行内相同文字保留普通注释内容，明确闭合标记优先结束当前注释。行注释的真实结束符采用同一注释样式，逐物理行传播保留续行上下文，未到结束符时不提前丢弃当前片段的有效状态。

同一编号多次出现时，规则按原出现位置对应：行注释的开端、续行与闭合分别对应，块注释 `03` 的各个开端使用 `04` 同位置的闭合项；八组分隔符各自保留开端、转义和闭合的对应位置。某位置缺少闭合或转义项时保持为空，不借用其它位置的规则。`((a b))` 中以 ASCII 空格分隔的候选属于同一位置，可以共用该位置的对应规则；候选仍采用最长匹配，同长优先原顺序。

编号字段中的 `((EOL))` 明确展开为 CRLF、LF 和 CR 三种实际结束符，普通字面的 `EOL` 保持字面含义。明确行尾闭合优先于行注释续行，分隔符的闭合结束符保留该分隔符样式。上下文和匹配缓存都包含实际对应位置；规则切换仍撤销旧词法状态。候选组展开后继续计入整份规则的 65536 项容量，超量时不发布部分样式。非 ASCII 标记按完整 UTF-8 标量匹配属于 Nate 的增强行为；忽略大小写也不允许替换字符代替截断的原始标量。

数字使用 `Numbers, prefix1`、`Numbers, prefix2`、`Numbers, extras1`、`Numbers, extras2`、`Numbers, suffix1`、`Numbers, suffix2` 和 `Numbers, range` 七组原规则，兼容两类前缀、前缀附加字符、要求后缀的附加字符、独立后缀、负号扩展、范围和科学计数。各数字组按原定义顺序匹配，不改写候选顺序。`Global` 的 `decimalSeparator` 可选 `0`（默认点号）、`1`（逗号）或 `2`（两者），不随系统地区改变；非法设置拒绝整份定义。数字关键部分只接受 ASCII 十进制位，数值前后缀按明确选项仅折叠 ASCII 大小写。

数字须在真实空白或当前启用组的结束外观处取得完整证据，文件末尾不虚构结束符。非法连续候选保留整体字面身份，不在内部标点后重新着色尾部数字。把 `E`／`e` 配为额外字符时采用该规则，其优先级高于科学计数。数字和结束外观不证明数值可计算或整份文档有效；其规则与其它语法共享行、工作量、取消和截止预算。规则算法来源及许可随应用保留在 `resources/licenses/UDL-NOTICE.txt`。

UDL 的完整行样式和后续上下文一次发布，嵌套过量时保留原上下文并停止本次呈现。单行最多 1 MiB、65536 个片段和 128 层上下文；规则最多 128 个列表、256 个样式及 65536 个候选，每项至多 64 KiB、候选合计至多 4 MiB。全部规则组共享 262144 个索引节点、33554432 步及所属任务的五秒截止；超量、取消或证据不足时不发布部分高亮、检查点或括号索引。规则和样式变化撤销旧分析，稳定视觉身份采用实际字段原字节，重新读取相同规则不会因临时身份改变矩形的资源证据。

UDL 折叠采用 `Folders in code1`、`Folders in code2` 和 `Folders in comment` 各自的 `open`、`middle`、`close` 规则。前向代码组可紧邻正文；后两组须取得真实空白或已启用前向规则建立的整词边界，`foo.begin` 不会单独识别其中的 `begin`，文件末尾也不虚构整词结束符。中间标记先结束前一分支，再开始后一分支。运算符优先于同位置的折叠规则，同组保持开端、中间、闭合的优先顺序。

注释内自动允许注释折叠组，分隔符内按对应 `nesting` 位启用整词折叠组；未声明嵌套权限的样式保持封闭。`Global` 的 `allowFoldOfComments="yes"` 将连续独立注释行组成区域，`foldCompact="yes"` 允许空白及仅含前向折叠符的结束行随前一块收起，两项默认均关闭。范围按实际 CR、LF、CRLF 物理行建立：块注释在行尾闭合后不会重复发布同一结束符，后续代码仍属于自己的真实行；这与原始 LexUser 在该边界的折叠行号行为不同。没有显式闭合标记的有效开端延续到当前完整正文末尾；不把这一范围当作语法有效性的证明。

UDL 折叠最多分析 64 MiB、1048576 行、65536 个层级及范围，词法传播和范围转换共用五秒截止；单行继续遵守 UDL 容量限制。缺少完整词法证据、取消或超量时整体保留正文可见。未定义折叠规则且未启用注释分组的 UDL 不启用折叠菜单，预装 Markdown 的原定义也不据此获得额外折叠规则。

传统代码页使用随包严格映射，映射来源和许可证保留在资源中。撤销历史同时限制操作数量和估计保留容量，至少保留最近一个完整操作；大操作可能单独超过容量目标。

圆括号、方括号和花括号按当前词法样式配对，光标前字符优先。编辑区标出匹配两端和未匹配字符；搜索菜单可跳转、选择整对或选择内部文本，内部选择也可定位包围光标的最小完整范围。UDL 保留原始样式身份，颜色相同的不同规则不会合并为同一词法作用域。

括号分析在后台按文档、修订和规则身份发布，每个视图只保留一个实际在途任务。等待期间移动光标、变更规则或关闭文档会使原导航意图失效。当前默认预算为正文 64 MB、单行 1 MB、262144 个括号位置及边界检查内 5 秒；超限会在状态栏显示暂停原因，不发布部分配对。此能力采用当前 Swift 词法规则，语言词法覆盖仍遵循前述边界。

“视图”菜单提供收起和展开当前块、全部范围及按第 1 至 8 层收起，行号右侧加减标记可单独切换。当前结构规则覆盖 ActionScript、BaanC、C、C++、C#、CSS、D、eScript、Go、Java、JavaScript、TypeScript、Objective-C、OScript、PHP、PowerShell、R、Resource file、Rust、Swift、Tcl 的花括号，JSON/JSON5 的对象与数组，以及 LISP/Scheme 的圆括号。普通括号映射只收起完整多行配对，单行配对和交叉结构不作为代码块；采用独立词法折叠的语言沿前述真实行层级处理注释、区域及未闭合起始结构。字符串与注释中的标点不冒充代码括号。

Python 按缩进和三引号字面区域折叠，Tab 按 8 列计算；空行和注释按非紧凑模式归属相邻层级，字面内部缩进不制造代码块。其层级算法以 Swift 适配 Lexilla 的 Python 规则，作者及许可随包保留在 `resources/licenses`。其它语言的缩进结构按各自明确支持的规则提供。

折叠复用括号解析任务，最多保留 65536 个多行结构。括号范围整理额外限制为 1 秒；Python 层级转换额外限制为 5 秒、1048576 个真实行及 3070 列缩进。各克隆视图独立保留收起状态；隐藏行按区间保存，上下键和矩形拖选跨过隐藏行，查找或跳转进入隐藏正文时展开目标范围。正文变化后先恢复可见，再凭修订映射和完整 UTF-8 端点证据恢复适用的收起状态。输入法组合期间临时展开，确认或取消后按实际正文重新呈现。折叠不修改正文、撤销历史、保存或打印内容。

Nate 是独立 macOS 产品，不加载 Windows DLL 插件，也不属于官方 Notepad++ macOS 发行版。文本格式支持不包含 Word、Excel、PDF 等容器格式的排版编辑。

## 数据位置

目录工作区使用独立目录树，默认停靠左侧。双击或 Enter 打开文件，目录按需展开，保留既有搜索结果。已读取目录每两秒检查变化，增删、重命名与目录类型变化会刷新相关层级；仍存在的所选条目、展开状态、正文光标和焦点保留。隐藏项、应用包和符号链接不列入树，子目录逐段拒绝链接与越界路径。默认单层最多 2000 项，全树最多 20000 项，最多同时读取并观察 64 个目录；单层枚举和排序共用 5 秒计算预算，超限或失败明确反馈，不发布部分清单。读取失败的目录持续标示，其他目录成功不掩盖失败。关闭或更换根目录会撤销旧读取与文件打开的发布权限。等待文件打开期间，新的正文输入、候选、光标或视图变化、查询变化和窗口切换会使原请求失效，迟到读取不取得标签与焦点。

“视图 → 项目面板 1／2／3”提供三个独立虚拟工作区，分别保留定义、选择和展开状态。面板的“操作”菜单支持项目与虚拟分组增删、文件引用加入、同级排序、显示名称修改和引用位置重选。虚拟改名和移除只改变定义，磁盘文件与已打开正文保留。“从目录加入引用”取得本次目录清单并保留空分组，后续目录变化由独立目录工作区处理。

项目工作区保存为 JSON 定义文件，建议扩展名 `.nateworkspace`。每个工作区最多 20000 个节点、64 层及 4 MiB 名称和路径原文，归档最多 8 MiB。载入只解释清单，引用可用性尚未检查；双击、Enter 或明确执行项目搜索时才读取引用文件。相对引用以工作区文件所在目录为基准，保留真实路径中的点目录与符号链接语义。URI、UNC 和 Windows 位置需要重新选择本机文件，外置或网络卷引用在访问前明确确认。未知格式、损坏定义、外部改写与同一文件的正文编辑会阻止覆盖；保存失败保留内存定义，未确认保存后需重新载入或另存为。退出前可返回面板保存未保存定义，或明确放弃后退出。

三个项目面板的当前定义、独立保存点、展开与选择、当前面板及显示状态随恢复周期保护，目录工作区同时保留根与树状态。重新启动保留项目的未保存编辑，原定义路径不自动获得覆盖权。保存点和原文件证据完整时，用户首次保存会在后台复验原定义的完整磁盘基线及解码内容，两者一致才继续保存当前编辑；证据缺失、外部改写或原保存结果未确认时需重新载入或另存为。待复验状态在再次启动后仍保留，不能把真正的保存失败当成恢复复验；定义路径往返改变会撤销旧读取的覆盖资格。引用文件不会自动打开。目录根先显示为待连接，点击刷新或首次展开后才读取原目录，并按真实清单逐层恢复展开与选择，不在启动时访问已断开的卷。后续鼠标或键盘树操作优先于尚未完成的恢复定位，后台刷新保留用户已经收起的根。

侧栏恢复采用独立串行通道，保留当前与上一份归档，每份最多 64 MiB，目录恢复最多保留 64 个展开路径。完整旧状态先保留，再按原磁盘基线发布新状态；损坏、未知格式、链接改向或外部改写停止自动覆盖，当前不可读时可显示上一份并保留原因。“工具 → 重新保存当前侧栏恢复状态”明确使用当前界面重建两份归档，不写项目原文件或正文。未保存的定义在异常退出后按最近成功快照恢复；正常退出选择放弃时，两份归档都不会重新引入该草稿。取消退出继续保护内存中的当前编辑；侧栏实际写入尚未返回时不能把退出视为已经完成。

“搜索 → 项目中查找”只搜索用户勾选的已载入可用面板，按真实文件名进行包含和排除，不遍历引用所在目录或按虚拟分组解释目录过滤。未载入及忙碌面板停用；偏好勾选会保存，但停用面板不计入实际范围。重复路径和硬链接按文件身份去重，已打开文件默认搜索内存正文，可切换磁盘内容；替换始终优先处理已打开缓冲区且可撤销，关闭文件先保留原字节副本再按固定基线写入。引用解释、实际读取和结果准备在后台完成，未知路径、缺失文件和未授权卷逐项显示，反馈列出实际面板、读取数量及未读取数量。外置或网络卷可明确选择访问、跳过或取消整轮。定义、面板勾选、页签、输入或选项变化会撤销旧计划，确认返回和每个后续文件开始前再次验证。

用户配置使用应用偏好，恢复快照存放于 `~/Library/Application Support/Nate/Recovery`。应用包内只放运行程序、资源和许可证。编辑、搜索与预览默认离线，不上传用户正文。

保存前历史位于 `~/Library/Application Support/Nate/SavedBackups`，与恢复工作区分别管理。

恢复存储保留当前、上一有效工作区索引和最近 100 份明确保留的关闭内容。首次成功检查点后尝试清理，随后在有检查点时每隔至少 60 秒回收无引用记录；清理先校验全部依赖，损坏、未知格式或超过处理预算时保留现场。恢复失败按有上限的退避重试，相同元数据和正文复用已有清单；工作区索引字节不变时只复验。分块与索引的计算在边界检查 30 秒预算，底层系统调用未返回时仍按真实在途状态处理。

“Nate → 恢复存储设置…”可查看当前实例的恢复用量并设置总量上限，默认 8192 MiB，支持 1–1048576 MiB。上限统计恢复根目录及分块目录中的全部普通文件逻辑字节，包括正文、清单、工作区索引、关闭历史、侧栏及未知普通文件；原文件、保存前备份和其它实例的恢复目录单独管理。原子替换确认前同时预留旧文件和完整新内容，超限不发布新的恢复入口。降低上限保留现有内容，已有快照仍可读取；提高上限后后续任务继续采用新策略，在途任务沿自己的固定策略收束。

同一目录的合作写入按登记顺序共享容量资格，工作区内的多个文档与索引共用一次预算；临时只读统计不会越过等待中的写入。统计最多处理 131072 个目录条目，不跟随链接、特殊文件或未知子目录。设置损坏或格式未知会停止新恢复写入并保留原偏好，明确应用合法设置后继续；用户配置包缺少恢复总量字段时沿用当前限制。设置中的清理入口只回收完成依赖核验的无引用内容，不删除受索引或关闭历史保护的快照。容量是应用内的逻辑文件预算，不替代文件系统可用空间或限制绕过应用直接写入目录的其它进程。

文件写入任务窗口同时展示工作区恢复、侧栏恢复和关闭内容保留的实际进度：等待目录、统计用量、当前文档与修订、已确认原字节和分块数、清单核验、依赖目录同步、上一索引保护、当前入口发布与无引用内容清理。正文计数完成不代表索引已经保存，入口确认与后续清理分别反馈；临时等待、未确认失败和已经确认入口后的后续异常使用不同状态。关闭任务窗口只停止观察，清除完成记录不取消恢复或删除磁盘内容；恢复进度只保留有界元数据和最近 64 项完成记录。

恢复索引发布前再次确认分块、恢复根及其父目录的同步与身份，字节相同的入口复用也确认依赖目录，避免沿先前未确认的目录同步直接报告保存成功。私有恢复文件的实际写入逐层拒绝目录链接，目录替换会停止旧动作；同一动作的目录身份用于统计、写入和入口复验，不因任务重试丢失来源约束。

命令行支持文件、语言、行列和 UTF-8 字节位置。用 `--new-window` 将本批路径、命名会话或目录工作区打开到一扇新窗口，用 `--reuse-window` 复用当前窗口。默认复用，两个选项互斥。只传 `--new-window` 会打开带空白文档的窗口。

已有实例运行时，请求通过当前用户私有目录转交。`--no-restore` 启动会保留旧工作区，可从文件菜单显式导入。系统授权或文件系统等待不会授予原文件写入权。读取可取消，超过等待上限不发布新标签。保存与恢复使用独立通道。

“文件 → 恢复先前保留工作区”可分别选择正文与项目、目录侧栏。正文作为新身份的独立副本追加，保留源标签顺序、活动标签、固定、只读、编码、换行、书签与选区，不自动关联或覆盖原文件；等待期间改变导航时只在后台加入正文，从侧栏发起也保留原焦点。侧栏会替换当前三个项目面板和目录根，未保存定义需单独确认，引用文件和目录保持未连接。侧栏可独立于不可读的正文恢复；当前侧栏、输入或导航改变后，旧确认失效。整批正文树在构建前检查当前剩余的 2 GiB 与 1024 文档预算，旧式完整快照需先解码原记录才能取得正文长度；超量不导入部分内容，也不改选较早的小快照。读取走独立通道，发布前可取消；发布后的内容按当前工作区继续保护，未确认落盘明确提示，原保留记录始终保留。

## 构建

使用 Swift 6.3.2 和 macOS SDK。执行 `bash scripts/package-macos.sh`，产物为 `dist/Nate.app`。脚本执行 release 构建、生成图标与资源校验清单、组装应用包并完成本地签名。

## 架构

| 模块 | 职责 |
| --- | --- |
| NateCore | 分块正文、坐标、选区、事务、撤销和文本操作 |
| NateSearch | 搜索、扩展转义、正则、预算和替换计划 |
| NateSyntax | 语言识别、词法与语言资源 |
| NateStorage | 严格编码、磁盘基线、安全写入、恢复、目录遍历和虚拟项目定义 |
| NatePlatform | 系统对话框、剪贴板、实例锁和进程调用 |
| NateUI | 原生窗口、段落投影、输入法、标签与查找界面 |
| NateApp | 依赖装配、文件协调、任务、命令与生命周期 |

文本核心是唯一正文来源；界面只持有视口段落呈现。后台结果绑定文档身份、修订和请求，发布前重新验证。恢复正文先同步，再发布索引，上一份有效索引独立保留。

逻辑行定位沿分块树累计已缓存的换行数，只扫描目标叶片，不为每次光标或结果定位反复查找其它行首。CR、LF 和跨叶片 CRLF 保留原字节语义；处于 CRLF 两字节之间的位置仍归属前一行，软换行不改变逻辑行号。

双击单词沿真实 UTF-8 标量边界定位，中文标点和 emoji 分隔符不会改变后续单词偏移，也不为选择单词复制完整逻辑行。单次整词选择最多 262144 个 Unicode 标量，超限只定位光标并显示原因，不把部分词作为完整选择；仍可拖选正文。

逐字移动、删除和覆盖输入使用固定 Unicode 17.0.0 扩展字形簇规则，保留组合重音、肤色 emoji、旗帜、ZWJ 序列、Indic 连写、韩文组合和 CRLF 的完整边界。边界读取直接沿分块原文进行，不复制所在逻辑行，也不归一化正文。删除或覆盖时若光标处于簇内部，会取得所在的完整簇；显式非空选区仍按实际选择编辑。一次多光标动作共享 262144 次标量读取及一百毫秒预算，全部范围准备成功后才发布，取消或超限保留原选择并说明原因，不执行部分光标动作。
